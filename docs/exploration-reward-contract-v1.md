# P11D 改变玩法的探索奖励合同 v1

## 目标与状态

P11D 不再把“箱子里的普通矿物更多”视为探索完成。工程范围于 2026-08-30 完成：遗迹、袭掠者
营地和路标各自提供一个会改变后续能力或计划的独特结果；真人逐结构体验保留 `Deferred`，不以
自动化代替主观结论。

## 奖励矩阵

| 正式结构 | 独特结果 | 能力边界 | 普通补充物 |
| -------- | -------- | -------- | ---------- |
| 遗迹 | `AncientCompass`（`Material::ID` 40） | 手持时 HUD 显示出生点的八方向与水平距离；不加载区块、不扫描结构、不改变移动或传送规则。 | 玻璃、小麦种子。 |
| 袭掠者营地 | `RaiderWard`（`Material::ID` 41） | 背包携带时，成功格挡后的恢复由 8 tick 缩短为 4 tick；仍要求武器、正面来袭、可格挡状态，仍消耗武器耐久。 | 煤矿石、铁矿石。 |
| 路标 | 既有 `WaystoneCore` | 保留放置、激活、守护战、回声试炼和一次性奖励能力；P11D 不复制或改写该持久状态机。 | 无新增替代主奖励。 |

两个新物品都是最大堆叠 1 的非方块、非工具物品，稳定字符串身份分别为
`hellomine:ancient_compass` 和 `hellomine:raider_ward`。它们只在末尾追加，不改已有 0-39
材料值；119 项图集中的专用图标同时用于箱子、背包、快捷栏和手持显示。

## 战利品与旧世界边界

P11D 新增独立的 `exploration_reward_version`，当前版本为 1，旧身份为 0，并将世界保存格式从
v11 升为 v12。它与 terrain v3 分离：地形轮廓、结构位置、结构选择和普通补充物数量均不改变。

- 新建 v12 世界保存奖励版本 1，未生成的遗迹/营地分别生成罗盘/护符。
- v1-v11 世界读取时确定迁移为奖励版本 0；保存升级到 v12 后仍保持 0，所以旧世界未探索区域
  继续生成旧版铁锭/面包主槽，不会因升级悄悄换奖励。
- 已生成箱子的 block entity 内容始终以区块保存为准；打开、清空、玩家存入和重开都不重新初始化。
- 当前 v12 缺少奖励版本、重复字段、负数或未来版本一律拒绝；旧版本提前携带该字段也拒绝。
- terrain 仍为 v3，settings 仍为 v8，目标定义仍为 v3/34 项，区块格式不升版。

## 能力实现合同

古代罗盘只读取已保存出生点和玩家当前位置，距离为 XZ 平面欧氏距离，方向固定为
`N/NE/E/SE/S/SW/W/NW`；距出生点不足 1 米时显示本地化“就在这里”。未手持罗盘时不显示导航，
因此玩家需要在导航与工具/武器之间做明确快捷栏选择。

袭掠护符只改变一次成功格挡后写入的固定恢复 tick；它不扩大格挡角度、不免除武器耐久、不降低
伤害、不绕过 UI/死亡/冷却门，也不改变敌人攻击判定。近战和投射物格挡共用同一恢复时长入口，
避免两条路径漂移。

## Deferred 真人验收

在同一新 v12 Release 世界中依次实际完成三类结构：

1. 从遗迹取得罗盘，远离出生点后手持，确认方向/距离能帮助返回且不会遮挡主要 HUD。
2. 从营地取得护符，分别在携带/不携带时连续格挡，判断 8→4 tick 是否可感知且不过强。
3. 完成一次路标核心取得、放置与独特阶段，确认它仍不是普通资源箱的同义结果。

记录找到结构耗时、奖励是否改变下一计划、是否长期占用快捷栏、格挡节奏与死亡原因。该记录可以
后置到统一真人窗口，但在完成前保持 `Deferred`，不得写成 `PASS`。

或新敌人。山地与天然洞口属于 P11-2，敌人身份化掉落与动作属于 P11E。
