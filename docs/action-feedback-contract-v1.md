# P11B 动作反馈与游戏汁水合同 v1

本文冻结 P11B 的表现边界、资源上限、settings v8 迁移和验收口径。P11B 只把既有采挖、
放置、近战、受伤与拾取结果表达得更清楚；它不改变命中判定、资源经济、敌人数量或掉落表。

## 玩法与表现所有权

- 世界固定 tick、方块交互和战斗系统先提交权威结果，再通过既有事件总线通知
  `ActionFeedbackTimeline`。表现时间线不能阻塞模拟、延迟伤害或重新判定命中。
- 采挖裂纹由 `MiningProgressSnapshot::normalized()` 映射为 0-9 共十级；未采挖为 -1。
  裂纹对象只在阶段变化时重建，最多 120 条线段。
- 方块破坏/放置粒子使用事件携带的方块材质，拾取粒子使用物品材质。反馈时间线最多保留
  48 个粒子，单粒子寿命不超过 0.55 秒。
- 第一人称持有物具有采挖摆动、动作反冲、接触保持和恢复姿态；视觉命中停顿最多 0.045 秒，
  只保持接触姿态，不暂停世界或固定 tick。
- 未命中、命中、格挡、玩家受伤和拾取使用不同的反馈状态；攻击冷却在准星附近显示，受伤方向
  保留既有方向三角。低生命提示只画屏幕边缘，不遮挡中心准星。

## 掉落物边界

- 拾取延迟结束后，掉落物只在 3 米内吸向玩家，吸附速度上限为 5 米/秒；进入既有拾取半径后
  仍由库存容量与原子拾取规则决定结果。
- 落地最多轻弹两次；掉落物总寿命为 300 秒，年龄复用 item 类型原先为零的
  `ActorSaveState::wanderTime` 保存，因此 world save 仍为 v11，旧存档默认年龄为零。
- Ogre 同时渲染的 item 上限为 256；超出上限的权威实体继续存在和更新，只跳过多余表现对象。

## 强度与回退

settings v8 新增 `feedbackintensity off|reduced|full`，默认 `full`：

- `full`：完整粒子密度、反冲、接触保持和低生命边缘提示；
- `reduced`：装饰粒子减半，反冲/接触幅度降低；
- `off`：关闭粒子、反冲、视觉停顿和低生命边缘提示。

三档都保留生命条、近准星攻击冷却、伤害方向以及 miss/hit/guard 的非震动标记，关闭不等于丢失
关键状态。v0-v7 原子迁移为 `full`；v8 缺字段、未知值、旧版本混入 v8 字段和未知版本均拒绝。

## 音频

方块破坏/放置、拾取、战斗命中/预警/格挡继续使用既有采样、并发上限、距离衰减和静默回退。
每次事件只增加确定性的音量微变体，范围为 0.94-1.06；相同 epoch 得到相同结果，不新增采样、
声部或无上限的音频对象。

## 自动验证与延期项

`HELLOMINE3D_WORLD_SMOKE_FOCUS=P11B` 覆盖 settings v7→v8、非法 v8、双语 key、十级裂纹、
粒子材质/密度/寿命/总量、强度回退、miss/hit/guard/hurt 区分、命中停顿上限、音量微变体，
以及真实世界中的掉落物吸附、寿命与拾取路径。

2026-08-29 的 VS2017/v141 Debug/Release P11B 定向各为 84/84，Release 完整
`WorldRuntimeSmoke` 为 786/786，`ResourcePackSmoke` 为 80/80，客户端双配置零错误编译。
真人 Release 动态观察仍为 `Verify/Deferred`：应检查裂纹节奏、手部接触感、命中/格挡/未命中
辨识、低生命遮挡、掉落物吸附和三档强度的舒适度。自动化不得把这些主观观察记为 PASS，也不
阻塞 P11-1 的工程开发。
