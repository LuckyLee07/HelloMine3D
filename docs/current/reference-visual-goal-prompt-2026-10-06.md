## 3. 完整实施范围

### A. HDR 收尾与生命周期

复用首版真实浮点 probe、颜色转换、旧模式语义与坏 shader 拒绝。补实际客户端 resize、切世界、切档重启、销毁和异常回退，验证离屏目标不绘制 HUD，Alpha、深度和数据通道保持。

持续核对地形、植物、角色、天空、水、玻璃、手持物、选取／裂纹、碎屑与地下背景的颜色域。保持固定曝光，新的颜色采样和 mip 修正放在材质批次，不用自动曝光、景深或运动模糊掩盖基础问题。

坏资源、shader 编译／实际链接错误与能力不足分别处理。旧 post Off／On 和旧资源包兼容保持；格式／能力问题完整回退，资产缺陷明确失败。

### B. 建筑套件、正常交互和资产制作

将两种样件扩展为约 10–12 类可用部件：石砖、半砖、台阶、檐口、瓦台阶／瓦檐、木梁、栏杆、窗框、窗台／花槽和灯具。先保证造型及用途，再统一材质；拱门和屋顶可用有界多格组合，每个 v2 形状仍单格内最多 8 盒、四向。扩大格式前明确合同和预算。

补方案中的逐面语义材质、UV 比例、碰撞／选取属性、缓存和面剔除。World 拥有状态与 revision，Ogre 仅持有视觉副本；编辑、边界 MeshDirty 和上传确认接入原流程。拆清 Alpha、邻面遮挡、整层封闭、AO 与格级阻光，部分形状不得误封层、隐藏邻块整面或让室内全面漏光。

旧 ID、v1 形状及既有 metadata 保持，新 ID 追加，合法保存值和必要迁移明确。新部件在世界、反馈、手持、掉落、库存和地图保持可辨的同物身份。四向放置、登阶、空隙选取后方、挖掘拾取、玩家／生物碰撞和卸载返回真实可用。

提供正常获取路径，优先接入成本合理的制作配方和本地化，不让新能力只存在于诊断库存或 Ogre 直接摆设。保留可编辑源、确定性导出、预览和正式资源清单，记录第二栋制作、整合及返工成本，修复阻碍复用的格式／工具问题。适用时可用图像生成技能制作正式资产，记录来源并在游戏真实尺寸验证；概念图不能替代运行资源。

### C. 多通道材质与室内外光照

先完成浅石、粗石、陶瓦、木材四种关键材质，再覆盖样板需要的道路、金属、叶和花。明确颜色、normal 及 surface 中 roughness／metalness／emission 通道、profile 版本、layer／mip 对应与同一资源来源。新颜色正确 sRGB 采样并在线性域生成 mip，法线 mip 归一化，裁切保持覆盖；保护 UI 共用 atlas。

旧包整套兼容，新格式声明后损坏明确失败，不静默混拼不同包／覆盖层的颜色与数据。实际地形和建筑区分石、瓦、木的漫射／镜面响应，普通与阴影 shader variants、生态染色、裁切、雾和输出同步。法线方向、退化切线、逐面／四向与错误覆盖用独立参考和负例校准，不只检查配置 token。

校准已有稳定太阳阴影，验证低太阳角度、近接触、远原点和连续移动；仅有已测覆盖缺口时扩至最多两段。室内保留传播方块光的漫射语义，最多 8 个附近真实灯源提供方向／镜面受光，定义能量分工与源索引失效；最多一盏定向主灯用聚光阴影。源查询和缓存有界，放置／拆灯和区块卸载后更新。

### D. 真实水面倒影

实现 PlanarWaterReflection：一张有绝对像素上限的半尺寸线性 HDR 反射纹理、一台镜像相机、一个选定水位。按实际 framebuffer 与 Retina 倍率算预算，只绘制已驻留的世界、植物、角色和天空，不增加反射流送；排除水面、第一人称手臂、操作反馈及 UI，禁止递归。

使用正确镜像视图和裁切，独立绑定矩阵、相机、雾、光照与阴影，不篡改主视图全局状态。水面按 Fresnel、真实水深和波纹混合倒影；其它水位、水下、关闭档及能力不足完整回退。无效投影或裁切边缘不能拉成整屏色块。

正常转头、走近、入水出水、拆墙、增灯、填岸及卸载返回后，倒影与权威世界一致。编辑、相机和水位变化使缓存失效，不用静态图掩盖陈旧。统计附加阴影绘制、提交和 RTT，按测量决定频率，保持有限资源。

### E. 植被、抗锯齿与场景整合

协调自然树、地被、花槽与建筑的疏密和尺度，保证入口及通路，修复样板枝叶穿插和重复。自然树可复用，但“已有树”不等于方向完成；改变树冠时复核碰撞、阴影、风摆、natural-root 与远景 mip，不恢复已撤回方案作捷径。

比较有界的空间抗锯齿与当前平台支持方案，放在 UI 前，以连续移动的栏杆、叶片、屋瓦和倒影检查闪烁、模糊及清晰度。不强行引入缺运动向量和历史失效设计的 TAA。

完成街道、水岸、两栋不同布局建筑和可使用工坊，使轮廓、材料比例、部件尺度、光照与倒影统一。工程样件区可保留为测试设施，不作为最终街道全部内容。至少留一段可拆建区域检验真实编辑后的整体效果。

## 4. 引擎选择、授权与边界

优先当前 Ogre／GL3Plus。关键效果或维护成本出现已测瓶颈时，用相同场景、资产和动态编辑要求做有限引擎比较，再选择可运行路径。不先做全引擎重写，也不在必要瓶颈前只留下“建议换引擎”就结束。

不重做另一视觉 Goal 全部 V01–V10、旧冒险主线、所有生态生成或严格 AI 盲玩；仅回归实际受新渲染／部件影响的主线、地图、实体和世界状态。旧缺项留在原报告，不成为本次前置。

多人、天气／季节、流体物理、城镇 NPC、全世界细分体素、通用 mod 热重载、实时全局 GI 和光追不在范围。保留 1 m 权威格、旧存档、采集制作、机器、任务及奖励语义；新增持久状态先定义版本、迁移、备份、坏数据拒绝和容量。

常规设计、局部重构、修复、资产整合、验证和文档同步自主完成，不加人工批次确认。执行本提示词后，实质批次验证通过可按既有中文格式本地提交，只暂存本 Goal 文件；首版提交前核对完整文件和证据，保存现有工作。推送、发布、标签及合并 master 按另行授权，实际权限和安全边界照常遵循。
