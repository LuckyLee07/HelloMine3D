# 游戏 UI：野外行囊方向

用户于 2026-09-20 指出当前 UI 不像成熟游戏产品。该反馈优先于继续微调场景；
综合视觉 Goal 保持，本轮不把遮挡修复等同视觉设计完成。

| Before | After | Why |
| --- | --- | --- |
| 默认标题栏、大面积同色文字卡 | 带物品徽记的专用面板、细包边和嵌入槽 | 让界面属于体素探索世界，建立容器与物品的层级。 |
| 九个长文字按钮，反复显示“空” | 九宫格图标、数量角标、旁侧实际材质体积预览 | 扫描物品位置更直接，空位保持安静。 |
| 标题、说明、结果和按钮近似等重 | 标题／分区／次要操作提示三级层次，突出可执行制作 | 优先显示玩家要找的物品和下一步操作。 |
| 快捷栏与面板各自的圆角卡片 | 共享槽位包边、凹面、选中角标和按下反馈 | 形成一致的界面语言，选中与悬停不只靠文字。 |
| 小窗口里箱子与行囊一起滚走 | 固定行囊与关闭操作，箱内区域按空间适配 | 操作对象和返回入口始终可达。 |

采用现有真实物品图集与有界几何缓存，深墨蓝底、暖白文字、沙金选择与主要操作；
不增加虚构装备、容量、稀有度或拖拽能力。开关常用面板不加等待动画。
原有点击转移、预览不消耗、制作原子性、Esc 返回与存档规则保留。

r34 实施物品槽、储物面板、合成面板与快捷栏，r35 完成常驻 HUD 批次。机器、暂停/设置及
主菜单按同一方向继续实机评审；不能以首批完成宣称整套 UI 已达到用户要求。
双语三字号与窄窗口必须可读，截图、实际控件操作与性能分别记录。
首批已完成实现、限定画面／诊断交互与相关性能，干净候选为 `delivery-r34`；
证据在 `build/visual-upgrade-20260917/ui-integration-r34/`，详见[本批记录](../reports/game-interface-r34-2026-09-20.md)。
剩余批次未完成检查不记 PASS。

后续按使用频率推进，验证通过后分别提交：

1. **行囊与合成（r34，批次已交付）**：共享槽位、真实物品预览、固定主操作；覆盖空位、满背包、配方预览、制作成功及窄窗口。工具不可存入箱子是既有规则，本批不改容器持久化；该限制的明确提示纳入后续交互反馈。
2. **常驻 HUD 与地图（r35，批次已交付）**：已统一任务标题／当前步骤／进度、生命条和快捷栏层级；地图使用实际地表与地标信息，外框、方位和区域名减少装饰性噪声。危险提示与任务信息不能争夺同一视觉中心。
3. **机器与菜单**：机器输入、燃料、进度和产物建立方向关系；暂停把继续、设置、保存出口分组；世界列表突出名称、地形版本和最近状态，减少默认表单感。
4. **整合反馈**：统一悬停、选中、不可用和失败原因；复查中英文、0.85／1.0／1.25 字号、640×480 与 1280×720，以及明暗场景中的对比度。高频操作保持即时，不以长动画延迟输入。

常驻 HUD 的具体设计约束：

- 左上任务区把当前目标作为第一阅读层；旅程总数与进度作次级信息。限制面板占宽，给右上导航留出安全间距；长说明按可用空间折行，完整说明仍可从暂停页查看。
- 底部以生命状态、五格快捷栏和当前物品名组成固定区域；状态出现／消失不推挤槽位。低生命同时保留数字与形状提示，不依赖红绿辨色，也不引入持续闪烁。
- 操作提示按当前对象显示，键帽与动词分离；危险提示、声音字幕和拾取消息使用不同预留区域，避免在准星和底部重复堆叠。
- 小地图继续读取实际地表和已发现地标。地图圆盘与下方标签分别计算可用宽度，修复英文区域名超出圆盘宽度就被裁掉的问题；比例尺与方位保持易读。
- 从 640×480／1.25 英文这一已知失败组合开始，再检查标准窗口和中文。覆盖长任务、空手／持物、受伤、通知出现与隐藏；r35 已按下方记录执行限定检查；未逐一遍历全部任务或完整正常玩法。

验收重点是信息可读、控件可达、操作状态可信、与体素世界一致。真实窗口和诊断夹具分开记录，
不会把开发者自己挑选的静态截图称为完整玩法或用户审美验收。

## 2026-09-21 美术方向修正

用户明确要求使用图像生成制作素材，并强调《我的世界》《迷你世界》一类方块沙盒题材。
写实木纹／黄铜草稿和随后橙色木框／密集铁角件像素草稿均被用户否定；
“像素化”不能只理解为把厚重装饰变成块状。用户认可基于实际场景制作的轻量整屏设计方向：
低饱和石灰色和深绿底、少量像素叶片／心形、克制边框，视觉主角仍是世界。

本批据此推进：生成素材承担底板与语义图形，文字、物品、状态和地图保持真实运行数据；
地图外圈使用轻薄刻度，区域名不再套厚框。所有素材必须放入实际场景按显示尺寸评审，
不以孤立的大图质感代替整体协调。草图与实机截图严格区分。

用户后续指出地图落地与草图不符；四向方牌、内侧刻度、地名和居中比例尺作为同一导航构件还原，
不能再简化为单独的北向圆标。比例尺数值与真实采样距离相符。r35 的已实施内容与检查范围见
[常驻 HUD 记录](../reports/hud-interface-r35-2026-09-21.md)。

当前最新干净候选为 `delivery-r35`。33 张分阶段实机原图、限定 CUA 操作及 12 次相关性能已检查，
任务长文覆盖初始任务的换行，未宣称全部任务、完整玩法或用户最终审美通过。
