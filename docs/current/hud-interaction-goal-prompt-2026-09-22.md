# HUD 交互入口 Goal

用户已批准并启动：让快捷栏、任务追踪和小地图成为可发现、可操作的游戏界面入口。

按顺序完成：

1. 明确第一人称捕获鼠标与 HUD 自由指针的切换，快捷栏 hover 高亮、真实物品详情、点击选槽；查看信息时暂停单机世界并防止关闭点击穿透。
2. 点击左上任务区打开任务日志，展示真实任务要求、进度、前置、可选与完成状态，并可追踪可进行任务。
3. 点击右上小地图打开 3D 区域地图，以真实已观察地表的材料／高程显示体素地形；支持旋转、缩放、平移、玩家定位、已发现地标和选点详情。
4. 在普通路径验证入口、返回、失焦和切世界，核对像素风格、中文／英文及窄窗口；完成必要自动回归、性能和独立客户端交付。

遵守 [HUD 合同](../contracts/hud-interaction-contract-v1.md)。不改变主线、物品经济、存档和地形身份，不加载远处区块来伪造已探索地图；无实际证据不得把 normal input 标为通过。保护用户客户端，默认后台工作，少量工作包和图像，按小批次中文本地提交、不推送。当前范围高于此前后置的菜单、机器和天空工作，不在本目标中穿插它们。

退出：三个入口均在真实客户端可用，正常指针操作与输入隔离有当前证据，真实数据／状态／回退／生命周期检查通过，必要回归与性能通过，代码已提交，可运行客户端及明确剩余能力限制已交付。不得停在方案或只做静态装饰。
