# terrain v13 地貌多样化升级方案

优先级：投射物 r27 独立验证提交后立即开始，不插入其他美术小批次。
首批实现、工程回归、限定实机/性能及正常新建保存重开已完成；持续输入体验按用户决定暂缓。

## 现状与目标

升级前生产 v12 的八 seed 宏观样本共 133128 列。海洋 20.89%、山地 17.31%、沙漠 15.60%、草地 16.55%、疏林 14.15%、森林 15.50%；生态标签分布并不缺种类，但几乎共用 v5 的高度场。v10 仅对部分内陆作最多八格的高度修饰，v11 河道实际最多切低三格，v12 只调整植被。玩家看到的地平线、地表和行进节奏容易相似。

产品目标：用真正不同的地貌组织探索路线，让远处轮廓、中景植被和脚下地面同时具有差别；不是靠新增地名或颜色计数。

- 沙丘：连续弯曲沙脊与低洼沙谷；稀疏枯灌木、仙人掌，避免绿色平地仅换沙色。
- 岩台/峡谷：宽平台、分层坡肩与明显切谷；石/土/沙连续成片，保留自然接近路线。
- 林地盆地：林下低地、周围肩坡、密疏不同的树群，与开阔起伏草甸交替。
- 浅水湿地：真实浅水、弯曲岸带和露出水面的草岛；与海岸/低地连续衔接。
- 既有草甸、高山和海洋继续存在，承担过渡与视野开合。

## 实现边界

1. 追加 terrain generation v13，默认新世界使用；v1–v12 路径及其已保存区块不变。保持 world save v12，不修改用户存档或强行迁移旧世界。
2. 纯世界坐标规划连续混合地貌高度，最后决定生态和表层材料；不能按整数生态边界切换高度公式。保留有界采样，不同步加载邻 Chunk。
3. 优先复用现有 Sand/Stone/Dirt/Grass/Water 及树木/植物；新增 Wetland、RockPlateau 生态值只追加在现有枚举之后，并接入实际生成、小地图名称、材质生态行和自然敌人映射。
4. 湿地使用既有水位，包含实际水柱和干岛，不引入水流模拟或不受控的悬空水体。地面规划、放置、出生、洞口、结构和公开查询共用同一列。
5. 岩台的石质表层和湿地的植物放置需适配新生态；旧生态规则以版本隔离，不能顺手重写旧生成。

## 验收设计

- v1–v12 原始生产采样及四象限区块指纹不变；v13 八 seed、负坐标、边界、反向加载、重开与玩家改块保持确定性。
- v13 宏观样本八种生态均出现；沙丘/岩台/湿地分别挑选由生产调查确认的大片区域，检查真实轮廓、材质和水深。抽样点不能替代连片度和窗口原图。
- 高度保持 1..176；需要允许局部岩台陡坡，同时要求绝大多数陆地可通行、所有出生点安全、结构至少有一个干燥接近方向。具体坡差、生态覆盖及变化幅度已冻结在 [v13 合同](../contracts/terrain-diversity-v13-contract-v1.md)。
- 八 seed 保留木材、石、沙、草、煤铁、洞口及三类探索地点；实际区块检查植被不悬空、不落水，边界不出现生成裂缝。
- 双配置聚焦/完整 WorldRuntime、资源及相关存档回归。检查真实新世界菜单、保存重开；持续输入仍按用户决定暂缓，不冒充通过。
- 多处固定原图和连续相机观察；同包 v12/v13、同一工作客户端、普通/阴影及常驻/流送三轮性能，遵守现有 1.10 帧时间门槛，记录实际网格/驻留变化，不为地貌差异放宽限制。
- 首批完整实现和必要检查通过后即本地中文提交，后续材质/植被艺术深化另分批。
