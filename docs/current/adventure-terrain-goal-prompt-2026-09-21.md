### 二、必须形成的玩家可见结果

1. **区域有完整身份。** 目标覆盖开阔草甸与河谷、温带森林、针叶高地、干燥沙漠与沙丘、岩台峡谷、浅水湿地、雪线山地、海岸与岛屿等可辨认的生态组合。每类都要有独立的轮廓、植被／裸地比例、材料与色调，并设计相邻区域的过渡。地名只是结果说明。
2. **大、中、小尺度共同成立。** 大尺度有陆海、山系、谷地和盆地；中尺度有山脊、坡肩、河湾、湖岸、林间空地及岩体；小尺度有地表斑块和植物。远处能辨轮廓，中景能决定路线，近处有落脚与观察细节。局部奇观可以稀少，但普通区域本身也应有变化。
3. **水系参与空间组织。** 河谷、湖泊、湿地、河口和海岸形成合理关系，检查上下游高差、水面连续性与岸坡。实际水块、地形查询和玩家看到的水面必须一致；水流物理模拟不作为这次表现目标的前置任务。
4. **生态组合有差异。** 林地不能只复用同一种橡树的大小变化。根据地区需要补充能辨认的树型与地被，按海拔、坡度、温湿度、距水关系组织树群、灌丛、花草、裸岩、沙地和水岸植物。保留开阔地与可读路径，避免均匀撒点、花草铺满和树冠堵住所有视线。
5. **材质统一且有区域特征。** 协调草、叶、花、土、木、石、沙及新增材料的像素尺度、明暗和饱和度；解决已知四米重复纹样、规则色带和材料硬切。需要新素材时可使用图像生成，但必须在实际场景、真实显示尺寸下评审，接入正式资源清单。
6. **探索具有节奏与目的。** 让林间开窗、山口、河谷、海湾和既有遗迹／营地／路标形成观察点与目的地。检查普通出生点附近及自然探索路线，不依赖跨越很远距离的诊断传送才能看到丰富性。地标与地形、植被相互避让，资源和主线仍可达。

### 三、按可验证的小批次实施

1. **现状调查与设计冻结。** 对当前生产生成器做多 seed 采样，检查区域连片、地形剖面、区域过渡、植被重复和探索距离。冻结比较范围、路线、机位、版本与衡量方法，再修改实现。给出区域设计表和技术方案，随后继续实施，不能只交方案就结束整个 Goal。
2. **宏观区域与地貌骨架。** 让区域定义真正参与地形、材料和生态生成。评估现有高度场与局部有界三维密度场的分工；采用适合本项目性能和存档架构的实现。先建立清楚的区域身份与自然过渡，再深化细节。
3. **水系和区域形态。** 完成河谷／湖岸／湿地／海岸衔接，并逐批做出可辨认的沙丘、峡谷、高地和山地轮廓。统一实际方块、公开查询、出生、结构和植被使用的生成结果。
4. **成套生态与材质。** 逐区完成树型、地被、裸地及材料组合；用相邻地区的连续路线检查统一性与差异，避免只审查孤立截图。
5. **探索整合与交付。** 在最终版本验证普通出生、自然探索路线、采集、地标接近、保存重开和旧存档保持。修复发现的问题，交付可运行客户端、精简对照、必要报告与真实缺项。
