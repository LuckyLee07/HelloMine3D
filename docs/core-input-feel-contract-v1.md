# P11A 核心操作手感合同 v1

> Architecture Lab 迁移说明（2026-08-31）：工程合同保持冻结；功能交互改由
> `docs/ai-assisted-gameplay-acceptance-v1.md` 的 `AI-01` 至 `AI-04` 覆盖。Physical Input v2
> 保留为历史物理合同且保持 `NOT_RUN`，物理设备手感为 `NOT_CLAIMED`。

本文冻结 P11A 的工程边界、输入仲裁、settings v7 迁移和验收口径。目标是先消除
“一个物理输入触发多个世界动作”、后台输入穿透、回焦跳变和切换模式卡住等确定性问题；
AI/Computer Use 可验证功能链路，但不冒充真人物理手感结论。

## 动作与所有权

- 键盘动作继续负责移动、跳跃、潜行、冲刺、打开合成和食用手持食物。
- 鼠标世界动作固定为 `break_attack`、`use`、`place`、`guard`。默认主键负责
  `break_attack`，副键由 `use/place/guard` 上下文共享。
- 同一帧只能选出一个世界动作。仲裁优先级为：主键采挖/攻击；可格挡武器瞄准敌人时格挡；
  指向可使用方块时使用；其余满足放置条件时放置。执行层不得在一次 `use` 后继续追加
  `place`，也不得把 `guard` 从 `place` 布尔值复制出来。
- UI、容器、合成、设置和暂停拥有鼠标时，滚轮、按键和按钮只发给 UI；世界层收到空输入。
  UI 先收到回焦确认点击，世界动作门在所有已按下鼠标键释放后才重新开放。

## 绑定与移动模式

- 世界动作可绑定主键、副键、中键、侧键 1、侧键 2。
- `use/place/guard` 允许共享按键，因为它们由上述上下文仲裁；界面必须显示共享说明。
  `break_attack` 与任一上下文动作重复属于破坏性冲突，保存前拒绝并给出包含按键名的提示。
- 冲刺和潜行分别支持 `hold` 与 `toggle`，默认均为 `hold`。切换只响应按下边沿；暂停、
  菜单或失焦会清除切换状态，并要求当前按住的键先释放，避免恢复后误切换。
- “恢复默认”同时恢复键盘、鼠标、冲刺/潜行模式、灵敏度和垂直翻转。

## 视角与焦点

- OIS 相对鼠标增量只在设备边界转换一次：`角度 = 原始增量 * mouseSensitivity`。
  计算不接收窗口宽高或帧时长；拆成多帧与单帧累计必须得到相同 yaw/pitch。
- `invertMouseY` 只翻转 pitch 符号，不改变 yaw 或幅度；pitch 仍由玩家控制器限制在
  `[-89, 89]`。
- 进入可操作世界后捕获光标；暂停、菜单、容器、合成、阻塞弹窗或失焦时释放。
  失焦和回焦都清空帧内增量，回焦后的第一份相对增量丢弃，后台不产生世界动作。
- 客户端不得主动把游戏窗口置前；是否捕获只根据当前前台窗口状态决定。

## settings v7

v7 在 v6 尾部新增以下必需字段：

```text
sprintmode hold
sneakmode hold
mouse_break_attack primary
mouse_use secondary
mouse_place secondary
mouse_guard secondary
```

- v0-v6 使用上述默认值原子迁移到 v7；已有键盘绑定、显示、音频、语言和世界种子保持不变。
- v7 缺字段、未知模式、未知鼠标键、重复 `break_attack` 冲突、未知 key 或未来版本必须拒绝，
  且不能覆盖旧文件。
- 保存顺序固定，成功重载后所有新增字段必须逐项相等。
