# Q3 内容规模与长稳合同 v1

## 目标

Q3 在 Release Candidate 功能冻结后验证三件事：快速移动不会让区块/网格队列失控，
玩法人口与持久化压力保持有界，长时间运行不会破坏存档或持续增长资源。它补充 Q1 的
短时帧预算和 Q2 的单次操作计时，不能由短冒烟或 synthetic fixture 代替。

## 固定场景

正式场景使用 `HelloMine3DSoak.exe` 的 schedule v2、Release x64、固定 seed `20260820`，
由 `tools/run_release_candidate_soak.ps1` 顺序运行，所有进程隐藏且不并行。

| Profile | 负载 | 目的 |
| ------- | ---- | ---- |
| nominal | 视距 1；4 区块旅行半径；每 5 秒移动、每秒 1 次方块编辑、每 2 秒 1 组 Actor 生命周期、每 10 秒保存重载。 | 代表普通持续游玩，证明稳定常态。 |
| stress | 视距 2；8 区块旅行半径；每 2 秒移动、每秒 4 次方块编辑、每秒 8 组 Actor 生命周期、每 5 秒保存重载。 | 代表有界高压，证明队列、人口和持久化不会失控。 |

每次正式运行至少 1800 秒。两种 profile 串行执行，避免 GPU、磁盘、调度和进程常驻数据
互相干扰。开发者短探针可使用更短时间，但不得标记 `formal=true`。

## 不变量与预算

世界侧每秒检查：已加载区块不超过已存在区块；dirty、CPU ready 与 GPU buffered
section 之和等于 section 总数；更新队列不超过 4096；Actor 不超过 32；已存在区块
不超过 1024；存在待处理工作时，网格重建不得连续停滞超过 60 秒。每次周期性保存重载
还必须保留 seed、编辑方块、Mob 与掉落物，最终保存必须成功。

Windows 包装层每 5 秒采样进程：private bytes 峰值不超过 2 GiB，句柄峰值不超过
4096；去掉前 20% warmup 后，末值相对稳态最小值的 private bytes 增长不超过
256 MiB，句柄增长不超过 128。子进程必须正常退出，完成时间不得短于 1800 秒。

## 证据与判定

原始运行位于忽略提交的 `bin/soak_runs/`。正式摘要跟踪在
`docs/baselines/release-candidate-windows-hidden-v1/`：每个 profile 分别保留世界摘要和
进程摘要，并由 `q3-manifest.txt` 固定 seed、时长、配置和最终状态。任何一个不变量、
预算、子进程退出码或摘要缺失都会使脚本非零退出；只有 nominal/stress 均通过才关闭
Q3。压力场景允许速度下降，但不允许通过丢弃持久化工作、损坏状态或放宽上限换取通过。
