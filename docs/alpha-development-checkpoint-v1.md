# Alpha 开发检查点 v1

本文冻结 G6 之后、N1 之前的开发基线。它不是 Release Candidate 封板：目标是让后续
内容扩展拥有稳定的旅程、存档迁移、崩溃诊断和性能回归参照，而不是提前完成真人输入、
长时间压力和最终发行包验收。

检查点基于本地提交 `1066f3a` 的十步可玩 Alpha，形成于 2026-08-17。

## 冻结范围

- G6 十步旅程语义和 `world.meta` 版本 4 不再由后续批次隐式改写；N1 只能迁移并兼容。
- 版本 1-3 继续可读，版本 3 空旅程样本固定在
  `tools/fixtures/alpha/world-v3-empty-journey.meta`。
- `HelloMine3DWorldRuntimeSmoke` 用该跟踪样本证明旧库存和空旅程一起升级，不依赖测试中
  临时拼接元数据。
- Debug/Release 的世界栈均通过 `420/420`，H1/H2 崩溃契约均通过 `16/16`；验证启动和
  真实三帧隐藏启动全部退出 0。

## Alpha 性能参考

Q1 合同 schema 3 增加第七个场景 `q1-alpha-playable-v1`，身份固定为 Windows x64
Release、GTX 1050 Ti、驱动 `30.0.14.7212`、1600×900 隐藏离屏窗口、固定种子
`20260809`、位置 `3038 66 1922`、视距 8、
世界格式 4、无资源包和相同 GPU/驱动。它同时记录：

- 帧 P95/P99、超过 50 ms 的帧数和固定 tick；
- 启动到可用、进入世界到可控、进入世界主线程最大停顿和保存总时长；
- 最终区块/section、Actor 数和常驻地形缓冲字节数。

跟踪基线位于
`tools/fixtures/performance/q1-alpha-playable-v1.baseline.summary.txt`，其绝对预算为：启动
不超过 2000 ms、进入可控不超过 1500 ms、进入主线程停顿不超过 1200 ms、保存不超过
150 ms、常驻地形缓冲不超过 30,000,000 字节，Actor 数必须为 5。原始摘要 SHA-256 为
`580308F7625E625780D23A7B744DA8794B7FA8CBB1111804C674B47E5985D7E4`。

同条件复测位于 `docs/baselines/alpha-windows-hidden-v1.repeat.summary.txt`，原始摘要
SHA-256 为 `C88D8AC63F61532971652EE48DA805F14C15B41447A5B7E7CFE629088A77D51C`。
基线/复测分别为 P95 `26.939/28.557 ms`、P99 `33.782/38.435 ms`、超过 50 ms 的帧
`2/4`，R1 比较返回 `PASS`。

第一次采样曾出现 P95 `21.726 ms` 的异常快样本，与第二次比较会返回 `REGRESSION`。
隐藏离屏、关闭垂直同步的帧率容易受瞬时调度影响，因此不把该异常快样本选为门槛；选择
较保守的第二次采样，再用第三次独立复测证明阈值可重复。后续不得通过放宽本场景旧阈值
来掩盖内容回归。

性能合同现有七个场景。Python 验证器覆盖 524 个 schema-3 派生用例和 8 个旧格式兼容
用例，共 532 项；PowerShell 验证器覆盖 36 个结果用例。其余六个发布场景仍只有合同夹具，
不能宣称 Q1 已整体关闭。

## H2 崩溃 sidecar 与离线符号

受控崩溃在成功写出 dump 后生成同名 `.crash.txt`。sidecar schema 1 只记录文件名、构建
身份、PE/PDB 身份、异常地址信息、线程和 `upload_enabled=0`；拒绝绝对路径、个人目录、
未知/重复字段、非法范围和超过 16 KiB 的输入。详细合同见
`docs/crash-sidecar-contract-v1.md`。

最终 Release 受控崩溃生成 127,425 字节 dump。匹配的 EXE/PDB 精确校验 GUID、age、时间
戳和映像大小后，离线解析到含 `triggerControlledCrash` 的当前项目链接符号；增量链接 PDB
本次未返回源码行，因此工具明确输出 `source=unknown:0`，没有伪造行号。错误 PDB 返回
退出码 3 和 `symbol-identity-mismatch`。验证还证明崩溃前保存可重开、没有
待发布候选、普通启动不生成产物且全程没有上传。

H2 在此完成“安全产物格式 + 单帧离线符号工具骨架”。任意 dump 的完整堆栈遍历、发行包
符号归档体验仍属于 H2 后续收口；下次启动提示和干净包交付属于 H3。

## 后续入口

检查点关闭后按 `N1 -> N2` 推进：先把一次性 `AlphaJourney` 迁移为数据驱动、事件消费型
目标边界，再增加熔炉、冶炼和铁级成长。R3 真人输入、H3 崩溃提示、Q3 压力/长稳与其余
六个 Q1 场景的正式预算继续后置，但每个开发批次仍必须执行编译、定向回归、数据守恒和
旧存档迁移检查。
