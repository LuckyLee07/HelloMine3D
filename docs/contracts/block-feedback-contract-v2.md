# 方块选中与破坏表现补充合同 v2

2026-09-12 用户授权：将黄框改为贴合模型的选中高亮，改善挖掘裂纹并增加碎屑。
此补充替代 P11B v1 的立方体线段裂纹与屏幕空间方块粒子表现；其余玩法、音频、
settings 和反馈强度语义不变。

- 选中高亮和裂纹使用注册模型、metadata 高度、实际生态 tile 和透明遮罩；花草复用 Flora
  vertex shader 的连续风摆。深度测试开启，不高亮遮挡物后面的目标，不绘制包围立方体。
- 裂纹仍由真实 `MiningProgressSnapshot` 的 0–9 级控制，停止、转移目标、打开菜单或切世界
  即移除。裂纹是表面表现，不改变几何、命中、硬度、掉落、碰撞或 save v12。
- 开采中少量碎屑来自命中面；破坏/放置碎屑只消费已提交的事实事件。碎屑使用实际方块材质的
  局部贴图和世界坐标，受到透视、遮挡、重力与旋转影响；拾取反馈继续保留 HUD 表现。
- 完整破坏 burst 16 个，Reduced 减半，Off 不生成；开采中每 0.12 秒最多一个 2 粒子的 burst，
  不追补卡顿期间的 burst。屏幕与世界粒子共用 48 个上限，单粒子不超过 0.55 秒。
- 同一个粒子年龄对应同一个世界位置，不依赖渲染帧率；切世界清空派生反馈。粒子不进入
  Actor、掉落、库存、持久化或世界 fixed tick。
- 标准数组纹理和兼容图集均可用，关闭镜头反馈仍保留选中与开采进度。隐藏 HUD 不改变世界效果。

最低证据：受影响客户端/WorldRuntime 编译，P11B 定向与完整世界回归、资源正反例、GPU alpha/
裂纹阶段/生产 Flora 对齐检查，干净包多帧视觉与相关性能对照。正常输入步骤与诊断夹具分开记录。
不改写已有 Windows 证据，不声明人类审美或手感。
