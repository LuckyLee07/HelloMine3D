## 本批玩家可见范围

追加 terrain v10，仅重组新世界离岸内陆的宏观高度轮廓：在 v9 高度 `81..134` 的连续
区域，以 seed 和世界 XZ 形成宽尺度缓丘、浅盆地、鞍部与山麓肩部。目标是飞行时能读出
比 v9 更丰富的大地形层次，步行时仍是可通行的缓坡。v9 的生态和地表材质标签保持原值；
高度不高于 80 的岸线、浅滩和低地以及不低于 135 的高山脊保持原高度。

本批不加入河网、高于海平面的水体、真实水深、新方块 ID、新生态类型、新结构、洞穴重做、
存档格式、区块生命周期或渲染系统。旧 v1–v9 世界及已保存区块永久走原生成路径。
生成区块、公开高度/生态查询、出生、树木草花、洞口、矿物和地点规划必须消费同一 v10
列；纯规划不得同步加载邻区块。

## 修改参数前冻结的自动退出条件

1. v1–v9 的生产 `samples.csv` 与 `chunks.csv` 和冻结基线逐字节一致。v10 在八 seed、
   正负坐标、区块边界、正逆加载及独立生成时确定；存档重开保留 terrain v10、已生成
   区块和玩家改块。
2. v10 相对 v9 只允许改变旧高度 `81..134` 的列，高度差绝对值不超过 8；生态与地表
   标签逐点不变。最终高度保持 `1..176`，相邻格坡差不超过 3；旧高度 ≤80 或 ≥135 的
   岸线、低地和高脊高度逐点不变。
3. 八 seed 的生产宏观样本中，合格内陆列至少 45% 且至多 90% 改变高度；其平均绝对
   高度差处于 `2.0..5.5`，升高和降低各至少占合格列的 15%。每个 seed 的正负坐标均
   必须出现成片而非逐格噪点的变化，固定画面不得出现跨区块接缝、等宽直带或突然陡坎。
4. 八 seed 的安全出生、木材、草、煤、铁、沙以及 Waystone、Ruin、RaiderCamp 仍可
   找到并有至少一个坡差不超过 3 的接近方向；树木、草花、洞口、矿物和地点不得悬空或
   落到不合适地面。
5. 运行受影响的 gmake Debug/Release 聚焦与完整回归、客户端双配置编译、资源和存档
   回归。窗口阶段复用唯一项目客户端，将 v9/v10 固定画面和三轮性能合并在一次 Release
   启动中；相同夹具下常驻与快速流送的三轮中位数 P95/P99 均不得超过 v9 的 `1.10`。
   首次失败和逐帧原件全部保留。

固定画面对照位置必须从修改后由生产 C++ 调查选出，再冻结 seed、XZ、朝向、时间和画质；
不得根据截图临时换点。真实中文菜单步行、采集、保存重开按用户当前指令延期，可记
`NOT_RUN`，不能冒充 `PASS`。本批完成后单独本地提交，不推送、发布或打标签。
