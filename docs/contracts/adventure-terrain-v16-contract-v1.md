# 冒险地图区域骨架 terrain v16 合同 v1

2026-09-21 用户启动完整冒险地图地形生态 Goal。首批从当前 v15 出发建立区域骨架；后续水系、专用植物、材料和探索整合仍属于同一目标。本批不是整体视觉完成。

## 区域设计与实施顺序

| 地区 | 轮廓与通行组织 | 后续配套生态 |
| --- | --- | --- |
| 草甸河谷 | 低缓丘陵、开阔洼地，保留远处目的地视线 | 疏林、草花斑块与沿河通路 |
| 温带林地 | 中低海拔起伏及林间盆地 | 不同阔叶树型、林缘与空地 |
| 针叶高地 | 抬升的丘脊、坡肩及山口 | 锥形针叶树、少花地被与裸岩 |
| 干旱沙丘 | 成片有方向且弯曲的沙脊，谷间可行走 | 稀疏耐旱植物、沙石过渡 |
| 岩台峡谷 | 高台、阶状坡面与切谷 | 裸岩、坡积土和稀疏灌丛 |
| 浅水湿地 | 接近水位的低地、浅池与干燥岛丘 | 岸草、灌丛及疏散湿地树 |
| 高山雪线 | 连续高脊、鞍部和低谷 | 高处雪面、下部针叶林与裸岩 |
| 海岸岛屿 | 连续陆海边界、海湾与海中陆块 | 沙岸、石岸和低地植被 |

v16 先落实独立纯区域规划及其实际高度、现有表层材料与地形查询；针叶树、雪材料、成套生态及完整水系在后续版本交付，不能用临时复用的生态名称宣称它们已经完成。

## 生成与兼容

- 独立于 v5–v15 的高度叠加链。使用 seed、带符号世界坐标和固定范围的区域锚点，区域定义直接参与高度与地表计算；边缘连续混合，不根据离散标签直接切换高度。
- 大尺度陆海、中尺度地区轮廓、小尺度坡面共同组合。保持现有海平面 64；首批不加入水流物理或无界河网求解。
- 区块生成、公开高度/生态查询、出生、洞穴、装饰和地点统一调用同一版本的列结果。规划不读邻区块、不依赖查询顺序、不新增无界缓存。
- 新世界追加 terrain v16；v1–v15 世界仍走原路径，已有区块和玩家修改不重生成。世界保存格式保持 v12，生态及方块旧 ID 不重排。

## 修改前固定的验证协议

1. 在起始提交 `5d1945a` 重新构建 Release 生产 WorldRuntime，按既有 T0 八 seed 协议冻结 v1–v15 的列和区块输出摘要。候选逐版本对比，差异即失败，不更改期望消除漂移。原始列压缩留在本轮工作目录，保留摘要与工具入口。
2. 固定八 seed：0、1、42、424、20260807、20260809、8675309、325322。宏观范围 XZ ±2048、步长 32；出生邻域 ±64 的逐格采样；既有正负区块边界及 signed int 极值。高度 1..176，无截顶平台；相邻格差最大 8，宏观坡差至少 95% 不超过 2。
3. 七种内陆规划地区各自汇总占比至少 1%；每 seed 至少五种内陆地区，各类汇总至少一片连续 128×128 米核心区。海岸和海洋单独统计，不能将海下的地区标签计作有效陆地。统计只证明空间覆盖，不替代视觉。
   核心区还须具有实际海拔与起伏差异：高地和岩台平均海拔至少高于草甸 20 格，高山至少高于高地 10 格；高地、沙丘、峡谷、高山的核心区高度标准差分别大于 6、3、7、9 格。湿地核心的水下地表及至少高于水面一格的干地各占超过 10%。这些检查用于拒绝平地换标签，不表示全部轮廓已经美术验收。
4. 实际生成块与列规划一致；洞口、矿物与结构覆盖单独识别。正逆加载、负坐标和保存重开一致；旧 v15 的保存测试显式固定旧世界身份，新建默认版本由新增测试验证。
5. 基线与候选按同一八 seed、范围和路线比较区域分布与剖面。视觉选点按区域核心连片面积选择，截图前记录坐标；检查中心、边缘、海岸与出生附近，不因效果不佳改点。连续路线按地形可通行性选定后固定。
6. 执行纯规划 Debug/Release 定向测试、世界定向及完整回归，构建双配置客户端。后续窗口验证区分诊断相机和正常输入；最终同设置常驻/流送各三轮配对，P95/P99 中位数不超过基线 1.10，记录生成耗时、几何与驻留量。

## 交付边界

代码、聚焦/兼容/完整世界检查通过后可先本地提交实现批次，窗口与性能结果继续在同一执行记录更新。每批明确工程检查、实际画面和正常玩法的状态；完整 Goal 按总目标退出条件认定，不将本合同首批实现当作全部生态已完成。
