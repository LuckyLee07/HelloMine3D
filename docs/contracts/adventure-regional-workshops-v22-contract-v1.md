# 冒险区域工位 terrain v22 合同 v1

状态：B4d 三类区域建筑示例的生成、交互和存档工程实现；普通发现、画面、路线、
资源平衡及同机性能仍待 B4 集中验收。

## 空间与用途

- 在实际林地、河湖湿地旁或高地地点入口侧，选择可承托的 3×3 干燥缓坡，构造可进入的
  小工位。前方保持两格净空，入口与 v21 路径相邻；无法安全落地时保留自然地形，
  不强行覆盖水、陡坡、洞口或其他地点建筑。
- 林地工位以苔石、林地土和橡木构成带顶储物角，提供**空箱子**；河岸工位以砾石、
  淤泥和黏土构成窑炉台，提供**空熔炉**；高地工位以石头、砾石和橡木构成带顶作业台，
  提供**空手摇破碎机**。三者使用真实方块与原有容器／机器语义，可打开、使用、拆除；
  不以静态贴图冒充交互。已有三套正式配方仍供玩家在基地制作同类设备。
- 每个符合条件的地点至多生成一个工位和一个空方块实体，不额外投放物品或补给。
  地点原奖励箱、矿物和核心完全不动。远处找到的设备可被利用或拆带回家，这是有限的
  探索收获；玩家拆除后保存重开不再生成，避免重复取得。

## 版本、边界与成本

- 仅新建 terrain v22 世界启用；旧 v1–v21 的生成规则、已生成区块和玩家改块保持。
  world save format v12、物品 ID、配方、地点键和奖励哈希不变。v22 继续复用 v21 的地点
  候选、两种建筑布局和接近路径。
- 工位整个 3×3 占地落在单一区块，优先按地点稳定选择位选侧，另一侧为地形退路；
  九列都干燥、坡差至多一格、距离地点锚点至多四格才投影。周边树木来源在原有九格
  地点 halo 内避让；生成不加载邻区块。现有非植物障碍和其他地点占地不被覆盖。
- 每区块地点计划上限仍为四；每个实际工位最多 36 个块位写入、一个方块实体。
  空载机器只进入现有有界模拟路径，不新增独立 tick、实体种群、缓存或声部。

## 必要证据

`ADVENTURE_WORKSHOP` 双配置检查冻结种子的三个实际区域、材料组合、净空与机器、
旧 v21 地点建筑及奖励不变、正反区块生成、原容器打开、空载状态、保存重开及拆除后
不重生，并核对默认 v22 身份。`ADVENTURE_APPROACH`／`ADVENTURE_LANDMARK` 复核
v21／v20；Release 完整世界和双配置客户端编译。普通采集、进入、带回建造、画面与
性能另按 B4 集中实机验收，不用无窗口工程检查替代。
