# 冒险世界前期引导合同 v1

承接[体验规划](../current/adventure-experience-plan-2026-09-22.md) B2；已落地目标前置、定义迁移与状态指导，
危险与恢复机会、三个普通种子体验仍须后续完成。本文不将事件模拟当成普通玩法。

## B2a 目标与兼容门面

- 定义版本由 v3 升至 v4，原 34 个稳定 ID 及资源注册顺序保持。可见必做数量由 33 改为 32。
- `alpha.reopen_world` 保持可见、改为可选；它仍只在真正重开且前置已完成时完成，不自动补发完成标志。
  任务日志保留历史及未完成状态；此目标不再阻塞必经成长和最终目标链。
- `progression.craft_furnace` 前置为 `alpha.collect_mob_loot`，不再依赖保存重开。
  `survival.craft_bread` 前置为 `alpha.place_workbench`，不再依赖铁剑；面包配方、实际消耗和恢复规则保持。
- `combat.defeat_enemies` 前置改为 `progression.craft_iron_sword`，避免提前食物后催促准备不足的玩家战斗，
  也不要求满血玩家先主动受伤才能进入战斗目标链。食用教学仍只消费真实正向恢复事件。
- Alpha 十步兼容门面按原十位完成标志选择未完成步骤，不跟随通用并行机会变化；位值／ID 不重排。
  可选的保存重开仍具有第十位与原来真实重开的语义，不伪造完成。新 HUD 与任务系统继续使用通用快照。
- 目标只读取已提交领域事实；没有库存、生命、材料、战利品或结局权限。保持奖励幂等、配方发现与最终胜利权威。

## 存储与预算

- world save v12、terrain v19 和配置格式不变；新增语义使用已有 `objective_definition_version` 字段发布 v4。
- 读取目标定义 v1／v2／v3 时显式归一 v4，完成集合、部分进度、未知规范 ID、配方发现 token 和低十位镜像保持。
  不根据新前置推断过去发生过制作、消费或重开，不回滚已完成旧目标。
- 保存只发布当前 v4；零、负数、未知未来版本以及计数／重复 ID／镜像错误继续拒绝。
  使用已有临时文件、原子发布、备份及损坏回退流程，不新增旁路写入或独立存储。
- 定义最多 128 项、完成／进度集合分别最多 256 项，机会最多 3 项；B2b 用三槽固定数组选择机会，不全量排序、不增加持久缓存或生成查询。

## B2b 状态指导与近期机会

- `World::getObjectiveSnapshot` 从玩家 Actor 读取生命／上限、食物冷却及世界模拟时钟，
  经 AlphaJourney 传入只读 `ObjectiveGuidanceContext`。不把渲染颜色或设置当作昼夜真值。
- 基础注册表的食物机会在工作台放下后进入近期列表；实际受伤、持有面包且无冷却时恢复优先。
  满血、死亡或冷却期间不提示立即吃面包；没有面包时提示当前种子／小麦对应的供应步骤。
  无效生命输入不声称可以治疗，查询不完成目标，也不改库存、生命或配方发现。
- 每日 tick 9000 至日末提高照明／落脚点优先级，次日恢复普通次序；仍只选择已满足前置的目标。
  火把指导核对当前煤矿石与原木，门核对木板／门库存，不因过去取得材料就声称现在仍有。
  木板放置进度不证明房屋封闭，提示继续检查墙、屋顶、入口和照明。
- 最多 3 个机会，固定三槽稳定插入，同优先级保持注册顺序；扫描最多 128 个定义与一次玩家库存
  （当前 5 槽），没有地形／区块查询、实体增长或随世界规模增长的工作。移除重复的当前项扫描。
  独立自定义目标注册表保持原排序。手动追踪继续优先于自动机会，不能自动清除玩家追踪选择。
- 指导 key 是临时快照数据；完成／锁定日志仍显示原始说明。HUD、暂停及任务详情使用同一本地化
  指导入口，食用键从实际绑定显示。相同任务状态变化时重新展开 12 秒说明，不增加弹窗。
- save v12／terrain v19／objective v4 不变，无新增持久字段、迁移或旁路写入。
  双语目录各追加 18 项指导 key，保留原目标说明与 locale fallback。

验证扩展同一 `ADVENTURE_PROGRESS`：满血／受伤／冷却／死亡／缺材料负例、入夜和实际世界时钟桥接、
真实保存恢复、稳定只读查询、双语与改键。受影响 Debug／Release 客户端及资源构建，Release 完整 WorldRuntime。
