# V07a 动物轮廓与动作过渡

在已有绵羊、林兔、湿地鸟上精修，不新增物种、行为、碰撞、奖励或持久字段。
保持每动物8盒／96三角形上限、自然种群24／近处12、48次查询和64实体调度预算。
V07e修复已有一格台阶规则在普通小步下卡住的缺陷；不扩大动物碰撞尺寸，
混合高低角支持、源体积与扫掠净空以[动物生态合同](adventure-wildlife-contract-v1.md)为准。

- 校准三种身体、头部、耳／喙和四肢的相对比例，继续以真实物种碰撞尺寸缩放。
  表现几何可小幅超出碰撞盒，不能反向扩大攻击／碰撞范围。
- 四肢围绕腿根运动，头与附件围绕共同颈部；兔耳额外绕耳根。姿态平滑后重新计算
  连接偏移，不能单独插值偏移造成接缝。兔子后足同相蹬地，羊／鸟保留交替迈步。
  足盒旋转后最低角不能低于复制的支撑平面；必要时仅抬表现根部≤4厘米，不查询地形或修正碰撞。
- 渲染拥有固定大小的动作历史，不外推穿墙。V07d由World成功移动分支复制路径类别，
  Actor按时间保留最近8个非零已接受段（起点、终点、时长、类别和序号），不写入存档。
  渲染按序重放全部未消费段：上台阶先在源XZ升高，再沿高处水平移动；下台阶先沿高处
  水平移动，再在目标XZ下降；连续下落沿真实垂直段平滑，不能把多tick累计高差推断为台阶。
  队列最多8段，剩余时长最多0.20秒；追加时保持当前进度和已验转折，不能连接成未验斜线。
  首帧、传送、历史缺段、容量超限、非法记录及超过0.25秒断帧明确重置到权威端点，
  这些重置不计连续平滑通过；dt为零、负数或非有限时不消费新段。
  朝向按最短角差收敛；步态只随真实可见水平位移累加，物种步长独立，停住时幅度收敛到零。
  觅食微动作由权威年龄和稳定实体ID决定，避免同龄群体完全同步，不新增世界时钟。
- 停留、觅食、游荡、逃离的关节过渡有界；暂停dt=0不推进，首帧／传送／过长断帧清理历史。
  关闭动画立即恢复中性部件，重新开启不从旧姿态跳回。每只新增动作历史≤192字节，
  不增加场景节点、堆分配、世界查询或全局缓存，随既有ActorVisual销毁。
  V07d的复制移动历史≤336字节、渲染移动队列≤512字节，原姿态历史≤192字节保持。
  动物局部前方为-Z，Ogre根节点使用负逻辑yaw，与Actor的(sin(yaw),0,-cos(yaw))行走一致。
  合法起点、World判定时地形不变的已验路径保证逻辑体积的通道；表现模型外扩和之后插入
  的新方块不由该历史证明全部无穿入。实际部件回归区分已有端点外扩与插值新增穿入。

验证：双配置纯运动检查最短转向、不同帧率、活动切换、停走、真实位移步态、暂停、
传送、强度关闭及非法帧间隔；逐帧关节／附件连接与几何预算；人工故障版本必须触发对应断言。
`ADVENTURE_WILDLIFE`双配置复核真实栖息／避障／预算／生命周期，Release完整世界和双配置客户端。
V07d另用真实Actor/World导出的段，链接实际客户端对象检查Ogre根、子节点变换及软件VBO
八角点，验证连续路径、暂停、三物种八方向和最短转向；生产源故障版本必须分别检出反向yaw
与恢复直线插值。该无窗口检查不计GPU绘制或普通玩法。
原shader不变时复用有效GPU证据；标准／兼容与动画关闭的生产画面另查。保留2–3张升级后原图，
诊断展示不计自然遇见，普通三栖息地遭遇、坡面连续行进和玩家工具方向继续保留。
