# 稀疏岩柱记路地形 terrain v30

属于视觉精修V03已批准的少量岩柱记路点；不关闭支脊／山口／河谷／区域过渡及完整普通路线。

- 追加`RockLandmarkTerrainGenerationVersion=30`，新世界默认v30。显式v1–v29的高度、方块、
  装饰、实体及旧存档首次探索未来区块保持原规则；已有区块不回填。save12、材料／生态ID、
  水位、矿物及奖励预算保持，用户客户端不原位迁移。
- 在现有v29局部地形之后追加紧凑岩柱。复用64米纯值锚点，以独立哈希位稀疏选择干燥峡谷／
  岩台高地；父水系列与既有v29高度均至少94米、坡度低、水影响为0，沙丘／湿地权重为0，
  抑制雪线区域。零权重也保护完整生态随机混合选择出的细尺度沙丘／湿地。
  约3×5米顶部、水平支持各轴不超过6米，单列相对v29只增加0..6格，总高度仍1..176。
  真实外围必须留两格头部净空的可绕行空间，不以模型或渲染位移替代实际方块。
- 地下、水下及低岸列不改高度；每个被修改列也重新核对区域、水系与地表保护。
  紧凑支持外高度与v29相同；不承诺全部材料／装饰也只影响同一范围，生态±2米坡度探针、
  树源与结构安全检查仍消费新版真实高度。
- 纯规划增加派生`rockCore`（严格等于相对v29高度增量为正），生态末尾选择已有Stone，
  保留此前水岸／雪线优先级。
  完整生态和轻量高度仍调用同一列入口。实际生成保持地面→洞穴／洞口→矿物→地下→植物→
  树→地点→接近线索→工位→清理顺序，不能最后补石填洞、压树或堵路。
- 固定九锚点邻域、128项／20KiB纯值缓存保持；键完整包含seed、version和有符号坐标。
  高度查询不依赖结构规划、完整生态、World／Chunk或邻块加载；极值用double／int64计算。
- 扩大地下回归发现seed20260807的两块洞室矿物在v29也完全悬空，真实六邻居除彼此外都是Air。
  v30在原洞室椭球内补最多16格阶状Stone肋，连接中心干路地板；煤铁露头同高度内移2米，
  各保留朝洞室中心的空气邻面，原两格矿位清空。包含两矿与原矿位，共最多19个不同写入格；
  原铁矿清空点属于既有显式矿列认证范围，不能将全部写入称为椭球内。全部写入保持原认证
  列／Y范围，不增加reach、矿物或奖励，不改三宽三高干路和水池。v1–v29保留原输出，
  旧版悬空作为明确故障对照，不将其旧语义改写为PASS。

   植物／树支撑及结构／洞穴通路；缺失块用拒绝哨兵，不能把缺块当空气通过路线。
   洞室露头逐矿检查空气邻面、非矿石支撑与六邻连通地板，比较真实完整区域煤铁数量；
   保留旧版悬空、封路、低净空与缺块的故障对照。
