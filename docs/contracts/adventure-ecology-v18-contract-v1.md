# 冒险地图成套生态 terrain v18 合同 v1

接续 v17 区域与水系，分资源接入、实际生成和整合验收推进。资源与实际生成已按小批次接入；本合同不是整体完成证据。旧生成 v1–v17 不改输出；改变新世界装饰和表层时追加 v18。资源接入可先独立提交，默认版本仅在生成实现及检查通过时切换。

## 玩家可见目标

| 区域 | 树群与地被 | 地表与路线 |
| --- | --- | --- |
| 草甸／河谷 | 稀疏橡树群、少量花草，岸边水生地被 | 连续开阔地，沙／砾岸过渡 |
| 温带林地 | 橡树与浅色树皮阔叶树形成混交片区，林下蕨草 | 腐殖层与草地斑块、林间空地 |
| 针叶高地 | 高瘦分层锥形树冠，树群随海拔与坡度退让 | 暗色林床、石地和上部雪线 |
| 沙丘 | 稀疏仙人掌／枯灌丛，局部水岸棕榈 | 裸沙为主，保留沙脊间通路 |
| 岩台峡谷 | 稀疏低矮地被，避免陡壁长树 | 岩壁、暖色黏土层、砾石坡脚及谷底沙地 |
| 湿地 | 低垂阔冠树、水岸芦苇和草丛，保留水面 | 泥岸与草洲交错，陆生植物避水 |
| 雪线山地 | 稀疏低海拔针叶树，上部退为裸岩与雪 | 雪线随区域权重和海拔渐变，不作整齐水平色带 |
| 海岸／岛屿 | 背岸树群、开阔沙滩与水岸地被 | 沙／砾／土岸结合，维持水面及落脚地 |

不能把统一树型仅换叶色当作生态完成；锥形针叶、轻盈阔叶、低垂湿地树冠必须改变真实方块组成。树群和地被按空间斑块组织，留出视线和步行空间，不均匀撒满地图。

## 数据与资源

- 树种外观可使用现有木材／叶块的持久化 metadata，值 0 保持旧橡树含义，新值只追加。树皮、断面和叶片分别选材质，网格合并键包括外观身份；碰撞、采集和保存使用同一真实方块。采集木材仍进入统一原木资源和既有主线／配方，不额外扩张多个木种配方体系。界面用通用原木说明这一经济规则，保留存档中的旧字符串 ID。
- 新雪、砾石、黏土、林床、苔石和淤泥若使用新 block/material ID，只能在末尾追加，并接入声明、图标、双语文本、碰撞、工具、掉落、放置、保存与资源清单。不能将只在 shader 中出现的颜色视为新增可采材料。
- 像素材质通过统一源图与可复现编译接入现有兼容图集和标准 texture array。新图块采用协调的像素尺度、低频明暗及受控饱和度；透明地被／叶片保留明确 cutout，不出现白色孔洞、黑边或其他 tile 串色。
- 图像源、提示词、编译参数和哈希保留在本项目美术来源目录；不用外部参考工程标识。运行时不读取未提交路径或生成服务缓存。

实际实现补充：草 metadata 2/3 分别用于低矮蕨草及芦苇，保持既有 0/1 含义。两种外观均保存在真实 TallGrass 方块中，采集继续使用成熟草的纤维／种子经济；不声称新增独立作物系统。树群来源固定为 7 米格内扰动锚点，四次邻近坡度查询仅用于通过初选的树。雪线由区域权重、海拔与 73 米变化场共同决定；v18 不修改 v17 的地表高度和水位。

## 生成约束

- 复用 v17 的统一列与水系，专用生态规则由纯查询派生。区域权重、温湿度、水岸关系和海拔共同决定组合；坡度检查只在候选树／植物需要时做固定数量查询，避免每列重复整套邻域生成。
- 树来源与冠幅有界，地标及入口避让共用既有 footprint。投影继续保护地表、水体和已有树干；树种、摆放顺序及跨区块部分由 seed／世界坐标确定，不同步加载邻区块。
- 旧存档已保存的区块与建筑不被重生成；旧版本继续使用原装饰与地表路径。颜色与材质可以统一改善，但不能悄悄改变旧世界方块或生成身份。

## 验证与批次边界

1. 资源接入：两种渲染路径可读取，图集语义／alpha／mip／清单校验；新材料真实放置、采集、工具与保存重开；树种 metadata 往返与基值兼容。
2. 生成：八 seed 的区域样本，真实树型数量／分布、雪线、地被／裸地比例、河岸支持和地标避让；正负坐标、反向生成及 v1–v17 基线对照。不能仅以新材料数量验收。
3. 图形：固定原区域及岸线机位，新增连续相邻地区路线，统一 FOV／时刻／画质；评审像素尺度、轮廓、植被密度、重复纹样及近远景。保留不达标事项并迭代。
4. 必要聚焦、完整世界与双配置客户端按风险执行；性能沿用最终整合版同机三轮配对 P95/P99 1.10 护栏，记录网格、驻留和生成成本。普通出生、采集和主线地点可达纳入 B4，不用诊断截图替代。

各小批次验证后中文本地提交。B3 完成仍需 B4 探索整合与 B5 最终交付，不能提前结束完整 Goal。
