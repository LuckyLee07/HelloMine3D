# 冒险世界 B1 天空与区域氛围合同

基线 `680f8a5`，承接[完整规划](../current/adventure-experience-plan-2026-09-22.md)。
本合同列出逐批新增语义，不表示 B1 已完成；B1a／B1b 已提交，B1c 区域氛围工程已实现，实景与性能待集中验收。日月／云外观按用户反馈另行修正。

## B1a 日月与云遮挡

- 默认大气使用有截角的方形日月，保持世界／天体坐标中的像素细节；太阳暖色边缘与内核、
  月亮冷色表面与有限坑纹可辨，不使用跟随屏幕的图案。既有世界时间、日月方向和亮度仍为权威。
- 日月方向参考世界 Z，太阳轨道不会与其重合；正午／午夜不得更换参考轴或翻转。
- 太阳半角投影尺度 0.052、月亮 0.046；轮廓仅做有界的像素边缘抗锯齿。
  不改变玩家 FOV 或模拟周期来放大天体，也不保证任何朝向都能看见太阳。
- 在连续方向上先求像素导数，日月投影／表面只在对应光晕的角范围内计算；
  不在逐像素分歧的分支中调用导数，也不对整片天空执行坑纹运算。
- 默认路径先绘制星空与日月，再用既有云覆盖合成；云遮挡同时作用于天体与光晕。
  薄云允许透光，背面射线不得再次画出镜像天体。
- `cloudLayerEnabled < 0.5` 保持之前 FS2 的完整云、圆形日月和光晕合成，逐像素对照。
- 不新增 uniform、shader 接口版本、纹理、网格、RTT、draw call、CPU 逐帧工作、世界／地形／存档状态。
  B1a 不改云密度和云形；B1b／B1c 继续负责云团、区域氛围和阴影复查。

## B1b 云团形态

- 默认云层仍为现有 156–180 m 的有界层，复用两个固定采样，不引入体积步进、纹理生成或天气状态。
- 云团形态使用世界坐标中约 7.67 m 的格子，先确定实体覆盖，再在格子边缘作窄而连续的覆盖过渡。
  每次层采样共用四个粗格噪声值推导细格四角，禁止扭曲坐标形成孤立细线；总计八个 hash 采样。
  格子与噪声随同一风速平移，不按帧重置，不固定到屏幕；在负坐标和云层上下边界保持连续。
- 入口／出口采样来自同一云柱场，用覆盖关系辨认底面与侧面；底面较暗、侧面接受方向光，
  云群间保留天空，不以整片模糊覆盖作为成形云团。两次采样是有界表现近似，不宣称完整体积云。
- 云团对日月、光晕、星空沿用 B1a 遮挡，昼夜照明连续；FS2 回退仍逐像素保持。
- 保持 B1a 的资源、状态和查询零新增约束。以 B1a 冻结包为本批性能基线，B0 包另保留用于累计对照。

## 验证

运行实际生产 GLSL：日月区分、晴空天体面积、非正面抑制、云遮挡比例、昼夜强度连续、
世界坐标稳定、正午附近旋转连续；使用旧 shader 及移除遮挡的错误变体证明检查能检出缺陷。
兼容回退逐像素相同；保留已有云上下边界、昼夜漂移和地平线检查。

复用运行时源码相同的已验证 Release 客户端，资源检查按双配置执行；仅改 shader 不冒充新 C++ 构建。
固定朝日／朝月、FOV 90／120 实景与连续帧；同机三对原版／候选帧耗，Off/Off、Medium/Off、
High/On 各档独立比较，P95/P99 中位数比不超过 1.10。最终 B1 还须完成八生态、四时段和动态阴影范围。

B1b 使用 `--cloud-form` 与冻结 B0 GLSL 对照，保留日月、遮挡、边界、回退与连续漂移检查，将云形保持检查明确改为
云形变化；增加真实云覆盖的留白／边缘宽度检查和相机位移抵消风移的世界坐标不变性。
检查草甸、林地、海岸及雪山的正常高度、朝日／朝月、云层内／上方，诊断转头与普通输入分开记录。

## B1c 区域光色与远景

- `RegionalAtmosphere` 是纯表现派生值，使用当前世界生成器已有的 biome 与自然表面高度，
  不用玩家建筑高度决定区域，不创建／加载区块，不改变生成版本和已生成地形。
- 世界对齐 64 m 网格，每个单元四角各查询一次 biome 和高度，最多八次纯查询；
  同单元后续帧只做 smoothstep 双线性插值。缓存固定四个值、最多 128 字节（当前 88），无堆分配。
  正负坐标使用同一 floor 规则，查询前预留整数边界；附着／退出世界清空，不跨世界复用。
- 林地与湿地稍增距离雾，湿地最浓；海岸冷色，沙丘／峡谷偏暖，高海拔区域更冷、更清透。
  雾密度倍率保持 0.80–1.30、单通道色彩倍率 0.90–1.07，不能用近景浓雾遮住危险和地形。
  自然高度区分山地高处与林地低处；地区交界用邻区真实采样平滑过渡，不按当前 biome 硬切。
- 同一派生色作用于距离雾、朝日雾与天空地平线；天顶和云受较弱的同向色调，保持低饱和。
  世界时间、太阳方向／强度、云速度／覆盖、水面颜色与实际光照权威值原样保持。
- 先求区域空气，再应用既有水介质；完全入水时雾色／浓度保持原语义，水线连续过渡。
  增强大气关闭时跳过区域查询／着色，保留既有云回退与独立水介质。
- 不新增持久状态、设置版本、资源、RTT、draw call 或阴影算法。B1c 本身不提升版本；当前代码为 save v12／terrain v20／objective definition v4。

区域纯检查 `tools/validate_regional_atmosphere.cpp` 按文件头编译（Debug 用 `-O0 -g`、Release 用
`-O3 -DNDEBUG`），覆盖预算、缓存重置、正负／极值坐标、跨区域连续、各时刻权威和水介质保持。
运行双配置客户端和 `V10C`，以 B1b 冻结包比较八生态，林地／海岸／雪山四时段、两 FOV、
功能关闭与连续视角。三档常驻和流送性能分别记录，P95／P99 仍用 1.10 护栏。
