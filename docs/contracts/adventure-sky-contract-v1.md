# 冒险世界 B1 天空与区域氛围合同

基线 `680f8a5`，承接[完整规划](../current/adventure-experience-plan-2026-09-22.md)。
本合同列出逐批新增语义，不表示 B1 已完成；当前实施 B1a 日月和遮挡。

## B1a 日月与云遮挡

- 默认大气使用有截角的方形日月，保持世界／天体坐标中的像素细节；太阳暖色边缘与内核、
  月亮冷色表面与有限坑纹可辨，不使用跟随屏幕的图案。既有世界时间、日月方向和亮度仍为权威。
- 日月方向参考世界 Z，太阳轨道不会与其重合；正午／午夜不得更换参考轴或翻转。
- 太阳半角投影尺度 0.052、月亮 0.046；轮廓仅做有界的像素边缘抗锯齿。
  不改变玩家 FOV 或模拟周期来放大天体，也不保证任何朝向都能看见太阳。
- 在连续方向上先求像素导数，日月投影／表面只在对应光晕的角范围内计算；
  不在逐像素分歧的分支中调用导数，也不对整片天空执行坑纹运算。
- 默认路径先绘制星空与日月，再用既有云覆盖合成；云遮挡同时作用于天体与光晕。
  薄云允许透光，背面射线不得再次画出镜像天体。
- `cloudLayerEnabled < 0.5` 保持之前 FS2 的完整云、圆形日月和光晕合成，逐像素对照。
- 不新增 uniform、shader 接口版本、纹理、网格、RTT、draw call、CPU 逐帧工作、世界／地形／存档状态。
  B1a 不改云密度和云形；B1b／B1c 继续负责云团、区域氛围和阴影复查。

## 验证

运行实际生产 GLSL：日月区分、晴空天体面积、非正面抑制、云遮挡比例、昼夜强度连续、
世界坐标稳定、正午附近旋转连续；使用旧 shader 及移除遮挡的错误变体证明检查能检出缺陷。
兼容回退逐像素相同；保留已有云上下边界、昼夜漂移和地平线检查。

复用运行时源码相同的已验证 Release 客户端，资源检查按双配置执行；仅改 shader 不冒充新 C++ 构建。
固定朝日／朝月、FOV 90／120 实景与连续帧；同机三对原版／候选帧耗，Off/Off、Medium/Off、
High/On 各档独立比较，P95/P99 中位数比不超过 1.10。最终 B1 还须完成八生态、四时段和动态阴影范围。
