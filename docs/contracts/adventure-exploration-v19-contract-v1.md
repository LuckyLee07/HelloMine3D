# 冒险地图探索整合 terrain v19 合同 v1

承接 v18 成套生态。新增生成输出仅进入 v19，v1–v18 的已有区块及后续生成保持；旧存档不升级或补写。原 v17 高度、水位和 v18 表层查询保持。

- 高山雪盖与岩体厚度保持 v18。材质修正使用源图实际行界裁切，避免相邻苔石污染雪纹理；不通过改变地形掩盖图集问题。
- 新树使用同一批纯洞口规划，在洞口及通道投影附近留下观察和进入空间；规划范围覆盖树冠来源 halo，不读取或加载邻区块。既有洞穴形状、地标内容和奖励保持。
- 营地在 v19 可选择平坦林间空地，继续使用原候选、坡差、入口及地标避让规则，补上大片森林区域缺少该类目的地的问题。旧版本仍限定原草地／沙地生态；不改营地构造、奖励或战斗。
- 蕨草仅替换标准 Cross 形状；资源包自定义几何继续使用原定义。真实草块的成熟状态、掉落和存档不变。
- 八个既有调查 seed 从普通创建世界路径出发。核对安全出生、附近实际木材和基本资源；以出生为中心的有界陆路调查检查相邻区域核心、水岸与三类探索目的地。记录步行候选路线、距离和失败，查询路线不能声称通过了真实玩家碰撞或正常输入。
- 在独立客户端从正常菜单创建世界，使用可用 Computer Use 完成移动、观察、采集及保存重开。工具限制只影响相应正常输入项；继续其他工作并如实记录，不通过诊断传送冒充步行。
- 最终版本进行原条件视觉对照、相邻区域连续观察、同机三轮配对 P95/P99 1.10 护栏，记录区块生成、网格和驻留。此前headless 成本或旧批次 PASS 不代替最终结果。
