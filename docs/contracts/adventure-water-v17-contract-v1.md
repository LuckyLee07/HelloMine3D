# 冒险地图水系 terrain v17 合同 v1

本批接续 `40cbb04` 的 v16 区域骨架，完成有方向的区域河谷、低地河道与终端／缓流浅湖。新建世界追加 v17，v1–v16 的生成身份、保存区块与修改保持；沿用水位 64，不实现水流物理或承诺全世界无内流区。

## 规划规则

- 以固定范围的有扰动流域节点构造连接。先为少量低地节点规划湖盆水头，再选择势能更低的邻节点，严格下降以排除有向环；湖盆及终端浅湖与入／出水河床共用节点水头，不能在干河床旁挖出孤立水坑冒充连通。高处延伸为干谷，接近海平面的部分形成真实河床和水柱。
- 河谷连续弯曲、宽窄变化，汇合处共享节点高度，不以随机断开的线段充当河网。河谷、湖岸与已有湿地衔接，并保留海岸连续性。
- 图规划只读取纯 v16 列，不加载世界或邻区块。若为成本复用局部计划，仅允许固定容量、按 seed/网格身份校验的线程本地派生缓存；正逆查询、切 seed、并发和驱逐后结果必须相同。
- 实际生成、地表查询、出生、植物与地标继续使用统一列。水下区域分别显示河道／湖泊，生态枚举只追加；原海洋、旧生态色和旧世界保持。

## 验证

1. 保留 v16 生产列/区块摘要以及 B1 的 v1–v15 基线，候选逐版本对比，不修改旧期望。
2. 沿用八 seed 宏观、逐格邻域、正负边界和 signed int 极值协议。高度 1..176、相邻差不超过 8，至少 95% 宏观坡差不超过 2；新增水体不得覆盖全部低地或把高地整体压平。
3. 固定区域中须出现连续河床、实际浅水和终端湖盆；每个节点的出边严格下降，所有低地水柱与既有水位一致。图的潜在方向不等于已验证全局物理流动；记录干谷、水道、湖泊和入海处的实际剖面。
4. 生产查询与实际块相符，水下不能生成陆生草花或树干。旧/新版区块加载、保存重开与新世界默认身份正确；新增生态名称与既有小地图、颜色和自然生成映射一致。
5. Debug/Release 定向检查、完整世界回归及客户端构建；冻结水系选点和干岸机位后采集画面及连续观察。沿用最终整合版的同条件配对性能护栏，不将 headless 成本当窗口 PASS。

本批结束仍不代表专用植被、材质、出生探索路线及整个 Goal 完成。实现和必要工程检查通过后中文本地提交，不推送。
