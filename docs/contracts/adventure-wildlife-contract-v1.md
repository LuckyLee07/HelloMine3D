# 冒险动物生态合同 v1

状态：B3 首批领域实现；模型、声音、普通窗口体验和完整性能尚待本批后续验收。

## 栖息与行为

- 草地绵羊、疏林与温带林兔子、湿地与河湖岸鸟使用三个独立 Actor type。
  沙漠、海洋和山地区不借用其中一种动物填充。普通世界按真实地形 biome、
  已加载地面和当前昼间自然生成，不修改地形生成版本或玩家建筑。
- 动物继承 LivingActor，但不继承 MobActor 的追击、攻击和敌人掉落表。
  停留、觅食、游荡与受惊逃离根据实际玩家距离、物种节奏和所在位置切换；
  无线索时在出生点附近活动。靠近动物可以惊起它；玩家可以伤害／杀死动物，
  当前不产生掉落，且击杀不计入“击败敌人”目标。未来若增加掉落须另行定义
  物品、来源、拾取和经济测试，不暗改现有食物进度。
- 移动前验证候选位置所在区块及四角已加载、脚下可站、头部无碰撞、无水体，
  相邻地面高差至多一格。没有区块加载、同步路径搜索或直穿障碍。

## 有界成本与生命周期

- 每世界自然动物最多 24、玩家 64 m 内最多 12；每 80 fixed tick 的自然刷新
  至多 8 个候选，只发生在白昼和活着的玩家附近。敌人的世界／本地 cap、
  夜间生成规则及难度档案保持独立。实体仍使用已有 64 项轮转调度。
- 行为每只最多 5 Hz 作一次新决策；预算拒绝时后续 tick 可重试同一步，
  拒绝时不查询地形。所有动物新增地面／避障探测合计每 fixed tick 预算 48 次。
  候选生成按最多 7 次、单次移动按最多 18 次预留；超过预算延后移动，
  不做补偿式追赶。结果与拒绝次数在 WorldDebugStats 中可见。初始模型几何预算
  仍受 B0 的每动物 8 盒体、96 三角形和总新增顶点 10,000 上限约束。
- 自然动物是临时种群：区块卸载时移除，切世界／重开后不从 world.meta 恢复；
  再次进入已加载合适生态时重新自然生成。动物没有专属持久标记、掉落或奖励，
  因此不引入重复掉落或新的存档字段。WorldSave v12、terrain v19、目标 definition v4
  保持；既有敌人／物品存储与备份规则不变。暂停时 fixed tick 不推进，动物也不移动。

## 验收边界

工程检查覆盖三类生态自然出现、独立行为与受惊、无世界同步加载、预算、
区块卸载、保存重开、击杀无掉落且不计敌人目标，以及原敌人生命周期回归。
这些检查不替代普通客户端中实际遇见动物、模型／动作视觉、密集区流送和性能对照。
