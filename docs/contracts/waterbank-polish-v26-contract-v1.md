# 河谷岸形与湖岸精修 terrain v26

V03／V06 联动批次：改变真实河床、岸坡与材料，让弯道和浅水提供落脚、绕行线索。
水面沿岸风漂移不等于水文流向，后续动态表现与普通入水／编辑验收仍单独收口。

- 新世界追加v26；v1–v25完整输出及保存身份保持，save v12／map v4／settings v11不变。
- 保留原512米水系节点、严格下降的出边与共同端点。只在边中段平滑改变宽度，汇流端点
  恢复原宽度与床高；弯道内侧形成宽缓岸和局部滩台，外侧相对陡峭，不能切断原湿润主槽。
- 湖盆保留开阔连续水面，岸缘以有界径向变化产生浅湾与浅滩，真实湖床提供水深变化。
  海平面仍64，不加入高处流体模拟；海洋基础列保持，干谷继续由实际高度决定。
- 岸滩材料依据真实弯道沉积与湿度，复用沙、砾石、土和淤泥；湿地、雪线和旧生态语义保留。
  草／树不得生在水中，地标和出生继续通过统一新版列及既有可达性规则规划。
- 固定邻域、固定容量缓存，不读邻区块；局部地貌缓存增加生成版本键，避免v25/v26混用。
  水系图几何仍与版本无关，可共享；查询包络须覆盖新岸宽，signed极值不得溢出。

   对全部旧版本逐一重跑，禁止更新期望消除差异。

   高度1..176，相邻高差≤8，至少95%宏观相邻差≤2；海洋列不变，水位64、河床底不低于58。

   内外岸截面不同，宽窄变化、实际浅水和可落脚滩台均有非零生产样本。

   地表材料与公开列吻合，水下无陆生植物，改岸保存重开不回填；出生木材与种植链不退化。
