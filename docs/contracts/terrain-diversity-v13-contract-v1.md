# 地貌多样化 terrain v13 合同 v1

2026-09-19 用户明确要求提高地形多样化优先级，投射物修复完成后立即实施。
本合同的实现/验证属于综合视觉 Goal；macOS 为当前平台，Windows 后置。

## 玩家可见结果

新世界同时具有弯曲沙丘、岩台与切谷、林地盆地、浅水湿地、起伏草甸及既有高山海洋。
各区域必须在高度轮廓、实际地表材料和生态组合上不同。沙丘不是沙色草原，湿地不是绿色海洋，
岩台不是普通圆山换地名。远景能分辨轮廓，近景能识别落脚地面；区域边界连续过渡。

新增 terrain v13，仅影响新建 v13 世界及其尚未生成区块。v1–v12 生成路径、生态枚举原数值、
世界身份和已保存区块不变，世界保存格式保持 v12。用户旧存档不迁移，不覆盖已编辑地形。

## 运行时边界

- 使用 seed 和带符号世界坐标的纯规划；连续组合高度后再派生生态/地表，不能由离散生态标签
  切换高度制造接缝。规划不得读邻区块、消耗可变随机序列或增加无界缓存。
- 生成区块、公开高度/生态查询、出生、树木草花、洞口与地点共用同一列。保留现有装饰 halo、
  洞穴/矿物/奖励职责和硬预算。
- 复用 Sand/Stone/Dirt/Grass/Water 与现有体素植物；增加 Wetland、RockPlateau 生态值时只追加
  枚举，接入生成、小地图双语名称、材质生态行与自然敌人映射。水面保持现有全局水位。
- 不纳入水流模拟、侵蚀求解、悬空岛、全世界河网、季节、动物系统或渲染架构重写。

## 实现前冻结的检查目标

1. 旧版生产兼容：沿用 T0 八 seed 和宏观/局部/边界协议，v1–v12 的 `samples.csv` 与
   `chunks.csv` 相对身份匹配基线逐字节不变。不能更改旧版期望来接受漂移。
2. 新版地貌：八 seed 宏观样本中八种生态均出现，每种汇总占比至少 0.75%；每 seed 至少七种。
   原 v12 干地样本中，至少 35% 的高度变化达到两格；全体干地平均绝对变化为 3..15 格。
   这些数值只证明变化量，不能替代原图和局部轮廓检查。
3. 边界与安全：所有采样高度为 1..176，截顶比例不超过 0.1%。一格坡差最大 6；宏观坡差
   至少 95% 不超过 2。允许有限岩壁，同时单独验证出生/结构通路，不将全世界视为平滑缓坡。
4. 连片与识别：从生产宏观调查按连片面积选出沙丘、岩台和湿地区域，并在截图前冻结坐标。
   每类至少检查三个不同 seed；128×128 密集剖面中，沙丘高度跨度至少 6、岩台至少 12，
   湿地须同时有实际水柱和干燥草地；补查林地盆地/草甸及海岸/高山过渡。保留全部选点和失败。
5. 真实生成：检查每类选定区域实际区块的表面与规划一致（洞口/结构明确排除并记录），植被
   不悬空或落水。八 seed 安全出生、木/石/沙/草/煤/铁以及三类探索地点仍可获得；地点至少
   有一个连续八格、坡差不超过 3 的干燥接近方向。保留可用洞口。
6. 生命周期：正逆加载和独立生成块指纹一致；v13 保存重开保留生成版本、已生成区块及玩家
   改块，未知生成版本拒绝。运行双配置客户端、定向和完整 WorldRuntime、资源及相关存档回归。
7. 视觉/性能：复用同一工作 `.app`，固定 seed/位置/朝向/时间/画质作 v12/v13 对照，保留因
   地表高度造成的真实机位差。新沙丘/岩台/湿地及过渡处实际原图和连续相机画面通过，普通与
   阴影路径正常；受影响常驻/快速流送各三轮，P95/P99 中位数不超过 v12 的 1.10。
   同时报告真实几何/驻留变化、headless 生成成本与失败，不放宽门槛、不筛慢样本。
8. 正常菜单新建、进入和保存重开验证 v13 接入；持续键鼠输入依用户决定暂缓，保持缺项标识。
   开发诊断、正常输入与主观审美分开记录；不以截图证明实际步行或资源获取体验通过。

本批实现、检查和中文本地提交结束后，再做后续艺术深化；不推送、发布或打标签。
