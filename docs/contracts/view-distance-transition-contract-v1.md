# 有限视距边缘过渡合同 v1

属于视觉精修 V02／V04。seed42 河岸 `212 70 -192` 的孤立叶团已定位为显示边界：
树根位于 `352 75 -159`，RD8需求最远到x351；真实132个木／叶方块六邻接连通。
同机位RD12可见整树，外侧新边界仍有残冠。不能为显示裁切改变生成布局或迁移存档。

## 范围与普通几何

- 区块需求、加载、上传、回收及worker预算保持。流送逻辑相机xz为中心，水平距离为
  `max(abs(dx), abs(dz))`，保留对角地貌。半边长 `end = RD × 16 − 2` 米；
  `start = max(end / 2, end − 8)`，末端向已有大气背景色连续退场，零覆盖丢弃。
  中心随逻辑位置连续移动；第三人称、观察相机和诊断扫视不改变需求中心。
- opaque／cutout用颜色过渡，水面同一覆盖率乘原alpha。不增加透明排序pass或纹理；
  近景材质、原雾密度、天空、云层、世界方块、碰撞、采集、保存与交互判定不改。
  标准数组／兼容图集、terrain／flora／actor普通与阴影路径一致，所有导数在新增discard前求值。
- 地下关闭退场，保留原几何和局部照明。强度复用驻留玩家眼sunlight，不混入火把；
  首个已知值锚定，后续指数平滑，未知保持；天光0.05–0.30连续恢复。换世界、重生、传送
  重置滤波。不新增逐帧世界查询或保存字段；设置视距1–32、切档和重进必须实际生效。

## 自然树的一致退场

- v24–v29复用真正生产树形的方块visitor和同一树源排除、来源次序；不复制另一套树形。
  查询模拟先前木干不可替换、后叶可替换叶的顺序。`SectionMeshInput`先复制resident块；
  只有owned范围发现木／叶／仙人掌才做纯派生查询，且实际id＋metadata与计划记录精确相同
  才复制root标签。builder在world lock外只读快照，不能回调World或生成器。
  这是一项表示关联，不是存档中的树木来源凭证；相同位置、相同值的替换不能区分来源。
- 每个自然树面的所有顶点携带同一个整数root标签，`flat`传递；greedy合并和共享顶点身份
  都包含root，不能先把两树合成一面。标签0走普通几何路径；手工mesh默认0。
  所有带同一根的可见木／叶面按根的位置计算同一覆盖率，绕过逐片元空间裁切。
- 树木范围为 `treeEnd = max(14, end − 6)`、
  `treeStart = max(13, treeEnd / 2, start − 6)`。RD≥2在普通末端前预留6米树冠宽度；
  RD1用13–14米，优先保留近处交互面。树根为整数角点，冠块±6米、顶点为根的[-6,+7]，
  任意距离小于6米的交互命中对应根的最大轴距离小于13米，因此保留完整覆盖。
  RD1根自身在最小16米需求内，远侧冠枝仍可能超出需求，不宣称整冠完整。
- 完全退场的自然树也停止方向投影；非树caster和地下投影保持。部分退场时维持原深度投影，
  不用屏幕网点伪造透明或重写深度比较。v1–v23／未知自定义生成器无owner，保留普通几何
  过渡；不声称旧树已经具备整树关联。异步未完成的网格、玩家主动破坏形成的缺干树及其他
  悬空原因仍需独立定位，不以这次已复现边界关闭所有植被问题。

## 固定预算与兼容

- owned16³ `uint16_t`标签表每快照增加8192字节；封闭mesh仍跳过全部派生查询。
  每次owner查询最多25根，每根最多1024次计划写入、4096条section记录，固定临时表约12KiB；
  不加载相邻区块，不增加无界缓存。必须测量实际几何、缓冲和查询／构建开销。
- 相对section的root x/z各5bit，范围[-6,21]，`1 + (x+6)×32 + z+6`，0为无owner。
  非整数、NaN、负数、越界和unused28–31轴码拒绝。跨垂直batch保留同一xz编码。
- `ChunkMesh`增加与顶点等长的float流，clear／adopt／共享身份一并处理；打包末尾uv3 FLOAT1。
  GPU顶点40→44字节，每顶点CPU流也增加4字节。实际顶点／索引数可能因不同树根不可合并增加，
  必须单独记录，不把10% stride增长当作总增幅。两类光源的40字节前缀及语义保持。
- GL3Plus按program复用VAO，不能依赖缺失attribute自动归零。角色、玩家部件、投射物和
  手持／掉落物ManualObject逐顶点显式写uv0／uv1／uv2及uv3=0，保留原纹理、光照和几何。
  新增的手工对象属性占用另列，不将地形缓冲实测增幅推广到所有GPU对象。
- 地形29、save12、map4、settings11、旧世界未来生成规则保持。生产生成序列重构必须与冻结
  v1–v29地表／实际块摘要逐字节一致。严格配对性能仍延期，崩溃、明显卡顿和容量失控仍处理。
