# 冒险目的地接近线索 terrain v21 合同 v1

状态：B4c 生成实现与无窗口验证；普通玩家发现、连续行走、画面和同机性能仍待 B4 集中验收。

## 生成与旧世界

- terrain v21 及后续新世界启用接近线索。已有 v1–v20 世界保留原版本；已生成区块从存档读取，
  玩家改块仍由原有区块保存规则保护。world save format 维持 v12，不新增持久字段。
- v21 沿用 v20 的地貌、水系、地点候选、锚点、两套建筑布局、容器内容和奖励。线索只落在
  建筑前门外侧，建筑占地逐格投影不变；不新增地点、宝箱、资源或目标 ID。
- 每个已选地点最多投影前方 6 格、宽 3 格的地表线索。林地以林床和苔石、河岸以砾石与
  黏土／淤泥、高地以石砾和岩石表达；河岸样式必须由入口前方的真实河流、湖泊或湿地列触发，
  不能只按地点名称着色。其余区域使用克制的土与石标记。
- 路线采用当前自然地面高度。水面、过陡列、建筑重叠和不可安全清理的障碍不强行改写；
  仅清理植物与树叶，保留玩家建筑及非可替换方块。树木来源在既有有界地点 halo 内避开入口，
  不加载邻区块、不建立新世界索引。可走性和视觉连续性仍需普通游戏实测。

## 验证边界

- `ADVENTURE_APPROACH` 双配置检查三个冻结种子的实际林地／河岸／高地地点、地面和净空、
  旧建筑逐格不变、v20 地点及奖励身份、跨区块顺序、v21 改块保存重开。
- `ADVENTURE_LANDMARK` 复核 v20 兼容；Release 完整世界回归和双配置客户端编译检查真实接线。
  普通发现和进入、远中近画面、建造收获及同机三对性能另外集中验收，不能由无窗口检查替代。
