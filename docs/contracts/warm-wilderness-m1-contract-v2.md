# 暖野 v2 首轮 M1 合同

2026-09-12 用户授权“开始首轮实施”，范围为
[视觉方案](../current/visual-upgrade-plan-v2.md) 的 `WV2-00..03`。
本合同冻结本轮新表现语义，不回写暖野 v1 的历史验证结论。

2026-09-12 用户查看首个实机候选后指出新版观感弱于旧版，并明确选择
“保留旧版清晰的方块质感，做更精细的升级”。美术目标据此修订：
保留有体积的方块树冠、清晰像素边缘和统一细节尺度；停止使用薄交叉卡片树冠与柔化手绘材质。
资源隔离、兼容性、mip 和性能护栏继续适用。

2026-09-12 再次实机反馈后调整：用户认为树冠仍不如旧版，且验证耗时过长。
当前交付候选撤回 WV2-02 叶簇几何与新叶贴图，恢复旧版立方叶及其贴图，保留其他材质升级。
以下与叶簇有关的原计划不再作为当前候选的实现承诺；原 M1 全部退出项尚未宣布完成。

2026-09-13 用户以封面与 R1 实机截图指出当前树冠观感不合格，随后明确要求落实
[R1 树冠升级方案](../current/r1-canopy-cover-style-plan-2026-09-13.md)并交付最终效果对比。
此指令仅修订**标准路径树叶外观**：可重绘 16 个树叶语义层及必要的叶面受光，
保留立方叶体积、旧图集兼容路径、v1–v5 生成与全部玩法/存档语义。
下文“沿用 v1 像素及 Alpha”只描述此前旧叶候选，**不再约束新候选的标准数组**；
旧候选包及其验收/失败证据保持原身份。叶壳、薄交叉卡片和跨格新几何不自动恢复。
新候选须重新冻结包身份、性能对照和全部受影响验收，未通过前不提交为 R1 完成版。

同日后续用户再次指出树冠色彩和轮廓不合格，否定斜切低多边形样板，并要求参考
《我的世界》的方块树。R1 范围据此**再次修订**：标准叶纹理改用原创方像素素材，
新世界橡树可使用 terrain v6 的错层完整方叶块；terrain v1–v5 的原树块布局和
旧存档版本保持，非树地貌、遗迹规划及其奖励使用 v5 语义。以下“只改标准树叶
外观”“不实施新生成树形”等旧候选范围条款以本段为准，不延伸到 R2/T1。
拒收的斜切样板、旧色包及原始失败证据保留；新 v6 样板重新验收，未获用户
明确确认前仍为 R1 `Doing`，不得本地提交为完成版或进入下一轮。

## 范围与退出条件

- WV2-00：冻结实际暖野 v1 源码/资源/包，核实固定场景并重采性能。
- WV2-01：128 像素自然材质母版、64 像素标准运行纹理、独立 mip 采样、版本化资源与兼容回退。
- WV2-02：单元格内叶簇、稳定形态、透明裁剪及阴影、密林成本控制。
- WV2-03：材质/叶簇/光色集成为正常可玩的林地样板，设置、干净 macOS 包、自动与窗口证据。
- 不实施 WV2-04..08 的新生成树形、水深、实体、手持或后续 UI 重制；设置入口调整属于本轮。
- 最终包须实际包含标准视觉路径；兼容路径通过不能代替标准路径交付。

## 不变语义

save v12、terrain v1–v5、方块/物品身份、生成结果、碰撞/选取/采集/掉落、光传播、
固定 tick 与世界生命周期不变；旧世界只改变表现。32 字节地形顶点和 4 字节索引保持。
新增视觉设置使用独立新设置版本，完整识别已有 v0–v8 并保留其偏好。
世界与 CPU mesh 不依赖 Ogre；GPU 资源只由 Ogre 所有者操作，快照/revision/取消边界保持。

## 资源和采样

- 19 张首组自然材质母版按方案清单制作，保存原始来源/提示与内容哈希。
- 64 像素标准路径首选 Texture2DArray，保留 16×16 语义地址、120 有效地址和 136 空槽。
  UI 保留独立 v1 图集；未重绘内容逐项标记沿用或派生。
- 每层独立 mip；过滤使用正确颜色空间与透明边缘处理，叶/高草 mip 保持 Alpha 覆盖。
- tile 身份与层内 UV 分开；greedy 重复边界使用连续 UV 导数；不得直接启用旧紧密图集全图 mip。
- 新资源格式有明确版本与完整校验；旧 v1 资源包和默认兼容路径继续工作。
- 仅在实际能力不足或用户选择兼容时退回完整兼容 profile；坏资源/坏 shader 不能静默冒充能力回退。
- profile 在方块注册和 GPU 材质创建前冻结；需要重建冻结资源的设置明确重启生效。

## 当前树冠与光色

- 树叶几何、内部面剔除、碰撞、选取、采集与保存块回到原有立方叶路径。
- 数组中的全部 16 个树叶语义地址沿用暖野 v1 像素及 Alpha，保留完整方块轮廓。
- 被否定的交叉叶片、叶壳、独立叶网格和 Alpha 阴影程序已从当前运行路径移除；源图和失败证据保留。
- 草、土、石、木、沙与高草的材质升级继续使用标准数组；UI 继续使用旧图集。
- 暖野 v1 夜间、阴影 Off/On、后处理 Off/On、大气回退继续有效。
- 本轮不增加离屏目标、跨格叶片、风动重建、世界光源或新渲染线程。

## 性能护栏（修改前冻结）

固定 seed 20260807、v5、FOV90、RD8、1280×720 逻辑窗口并记录实际 Retina 尺寸。
林地与密林分别冻结位置/姿态/时间及世界输入；不猜测岸线或场景内容。

- 阴影/后处理 Off/Off、Medium/Off、High/On，每组各三轮，5s 预热、30s 采样。
- 每组 P95/P99 的三轮中位数均不超过同场景新采 v1 的 110%；同时记录逐批与累计变化。
- 记录每轮最大帧与 >33/50/100ms 次数、mesh/上传/队列；保留异常样本，不能事后挑选最好三轮。
- 密林常驻地形 mesh 字节不超过同场景 v1 的 135%；单叶簇达标不能替代总量预算。
- 标准 64 路径新增纹理常驻数据相对 v1 不超过 16 MiB；计入兼容保留项，单列加载峰值。
- 未能取得可靠 GPU resident 数据时，报告实际格式/层/mip 计算值与可得进程值，不伪称硬件实测。
- 对相关区块流送路线补采，只有实际失败或共享机制改动才扩大到长期压力。

## 验证与证据

资源校验和坏包负例；shader/profile/数组绑定；MeshDirty 和叶边界/失效；设置迁移；
受影响客户端与测试目标 Debug/Release，最终适用完整自动门禁。
每项基于本版本；已有 v1 测试仅是基线，不记作新实现 PASS。

固定世界画面覆盖林地、密林、草地/林缘、岩地、已核实干岸、夜间/火把和强制能力回退；
动态闪烁与剔除需实际移动观察，静图不替代。
正常主菜单、创建/载入、移动观察、采集/换物、暂停/设置、保存退出与重启另行检查；
新增设置中英文及 0.85/1.0/1.25 缩放可操作。

诊断启动/夹具、实现者正常自测、独立 AI 与人类审美分开记录。当前必需平台为 macOS，
Windows 新验证独立列 NOT_RUN；不由 macOS 推导。
