# N5 生态与探索合同 v1

本文冻结 N5 的生态差异、版本化地形、轻量地标、目标链和性能身份边界。目标是在不引入
天气、村庄、地牢群或大型内容系统的前提下，让不同区域具有可读差异，并给玩家一个由
世界种子决定、值得寻找和带回的探索目标。

## 玩家路径

1. 玩家完成 N4 的煤炭掉落目标后，开始寻找发光的路标遗迹。
2. 沙漠自然生成 Brute；草原、疏林、温带林和海洋区域自然生成 Stalker，使生态差异
   同时影响可见地表、植物组合和敌人压力。
3. 每个 4×4 区块地标单元最多生成一座路标。玩家使用铁级镐破坏中心的
   `Waystone Core`，完成 `exploration.recover_waystone`。
4. 玩家把核心放到希望记住的位置，完成 `exploration.restore_waystone`，结束 N5 目标链。

## 生成身份与迁移

| 身份 | 规则 |
| ---- | ---- |
| `terrain v1` | 历史生成规则，不生成路标；所有 v1-v7 世界读取时固定迁移到该身份。 |
| `terrain v2` | 当前新世界规则，在原地形、洞穴、矿石、植物和树木之后增加确定性路标。 |
| 世界存档 v8 | 必须保存 `terrain_generation_version`；只接受已知的 v1-v2。非法或未来版本拒绝加载，并保留最后一次有效状态。 |
| 世界目录 | 把生成版本视为已知元数据；UI 同时展示 seed 和 terrain version。 |

升级旧世界只升级元数据格式，不改变其地形生成身份。这样旧世界中尚未探索的区块仍按
terrain v1 生成，不会因为客户端升级突然出现 N5 地标；新世界默认使用 terrain v2。

## 生态身份

地形生成器提供稳定的 `TerrainBiome` 查询，现有五类生态仍由世界 seed 和世界坐标决定：

| 生态 | 可读环境 | 自然敌人压力 |
| ---- | -------- | ------------ |
| Desert | 沙地、枯灌木、仙人掌或棕榈 | Brute |
| Grassland | 草地、草丛或玫瑰、稀疏橡树 | Stalker |
| LightForest | 草地、较疏橡树、草丛或玫瑰 | Stalker |
| TemperateForest | 草土混合地表、较密橡树和草丛 | Stalker |
| Ocean | 低海拔沙质水底、岸边棕榈或橡树 | Stalker |

敌人注册表缺少首选自然敌人时，生成逻辑只能退回到已冻结、允许自然生成的确定性候选，
不得崩溃，也不得绕过世界和局部数量上限。

## 路标生成规则

- 世界按 4×4 区块划分带负坐标支持的单元；每个单元最多选择一个锚点。
- 锚点从八个由 `seed + cell coordinate + salt` 派生的候选中选择最高的干燥地面；低于
  `WATER_LEVEL + 4` 的单元不放置路标。
- 候选与最终方块投影都只依赖世界身份和坐标，不依赖区块加载顺序、邻区块是否已加载
  或运行时随机流。
- 结构半径为 2，使用跨区块 `StructureBuilder` 投影。结构先清理有界空间，再放置石质
  平台、四角立柱、煤炭装饰、铁和玻璃，中心只放置一个 `Waystone Core`。
- terrain v1 必须跳过整个路标阶段；terrain v2 对同一 seed 必须产生相同锚点，不同 seed
  应能改变锚点。

## 核心方块和目标

`Waystone Core` 使用追加的方块 ID 20 和材料 ID，不改变任何历史编号。它是不透明、可碰撞、
亮度 12、硬度 3 的镐类方块，需要铁级（tier 3）工具；错误工具不掉落，正确工具掉落自身。

基础目标注册表由 21 项增长为 23 项：

| 目标 | 类型 | 前置 | 完成条件 |
| ---- | ---- | ---- | -------- |
| `exploration.recover_waystone` | `break_block` | `combat.collect_coal` | 破坏 1 个 Waystone Core。 |
| `exploration.restore_waystone` | `place_block` | 上一目标 | 放置 1 个 Waystone Core。 |

目标继续复用 N1 的事件消费、完成集合和 v8 世界保存；破坏失败、工具等级不足或放置失败
不得推进目标。

## 性能和可比较性

运行时摘要与逐帧 CSV 都输出 `terrain_generation_version`。所有会受地形内容影响的 Q1
场景把它列为身份字段，因此 terrain v1 的 Alpha 基线不会与 terrain v2 的地标场景被误判
为可直接比较。N5 只增加每个 4×4 区块单元最多一座、固定半径的结构；正式目标硬件的
快速移动、内容规模、内存和长稳预算仍由 Q3/Release Candidate 封板，不通过放宽旧预算
来关闭回归。
