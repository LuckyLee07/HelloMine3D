# 植被空间与树冠精修 terrain v24 合同 v1

属于[场景精修 V02](../current/visual-experience-polish-plan-2026-09-25.md)；
当前用户授权不设置人工核验，工程检查、代理视觉和普通路线自测分别记录。

## 生产行为

- terrain v24 只追加植物布局与树型规则。v1–v23 原生成输出、已保存区块、地下系统、地点、
  水位、地表高度和资源 ID 不变；world save v12、地图 v4、settings v11 不变。
- 同物种具有高矮、冠幅、偏冠和分枝差别；林缘较矮、林内较高，使用相连的立方叶团，
  避免连续等宽水平大板。针叶保持尖顶，桦树保持轻冠，柳树保留下垂，棕榈保留放射叶片。
- 树群内有确定性的林间空地；陡坡和接近雪线的密度渐减。地被保留低／中／高植物及裸地，
  水岸草丛随已有湿度、岸高和斑块组织。复用现有物种和 metadata，不增加新掉落经济。
- 7 米扰动锚点和固定候选 halo 保持；树型水平包络不超过既有 6 米，地面保留穿行高度。
  树型仅由 seed、世界锚点及纯值计划决定，跨区块投影不得依赖已加载邻块或随机调用顺序。
- 树木来源保留洞口、建筑、接近线索和工位避让；新树型包络对应的安全边距必须足够。
  植被不得覆盖实体地面、水、建筑或既有树干；不修改旧版本的投影规则。

## 证据与退出

1. 修改前后生产 T0-SURVEY 的 v1–v23 `samples.csv`／`chunks.csv` 逐字节相同；
   新版本冻结种子 42／20260807／239701883 的高度、水位、地下与地点身份保持。
2. 生产树型检查高度／冠幅／偏冠／分枝的真实方块差异、水平与垂直容量上界、连通性、
   正负坐标跨区块正逆投影和树种 metadata。检查根部、叶冠不替换水和石地。
3. 新旧规划的林缘／密林／空地、坡地、雪线和水岸抽样，真实生成树与地被支持、入口／工位避让。
   不以概率字段变化代替生产方块变化，也不以某个平均密度证明每条路线可走。
4. Debug／Release 定向 V24 和受影响旧生态／探索／地点检查；Release 完整 WorldRuntime，
   双配置客户端，v24 新建保存重开、v23 继续原生成、未知未来版本拒绝。
5. 当前工作包固定普通高度视角前后图及代理连续移动；三种子、林缘／林内／空地／岸边／坡地
   的真实普通路线覆盖按 V02 整合完成。风摆与阴影同相、根部固定另按渲染改动检查。
   严格三对性能继续 `DEFERRED_BY_USER`，生成容量、明显卡顿与无界增长仍须处理。

本合同不把单一小批通过当作 V02 全部完成；状态与缺项仅维护在阶段执行记录。
