# HUD 交互与探索界面合同 v1

用户于 2026-09-21 授权完整 Goal：快捷栏详情、可点击任务区和可交互 3D 地图。2026-09-22 实施。

## 输入与生命周期

- 第一人称游玩保持捕获鼠标；Tab 切换 HUD 指针，保留未被玩法重绑定占用的 L／反引号入口。底部提供双语提示。
- 指针／任务日志／地图拥有全部玩法输入并暂停单机世界模拟，防止查看信息时继续采挖、走动或遭受攻击。关闭通过 Tab、Esc 或界面关闭按钮返回游戏，不叠加打开暂停菜单。
- 编辑文字或 HUD 弹层打开时，Tab／L／反引号不转交输入给玩法，避免标记名称触发快捷键。
- 每次输入所有权转移丢弃累积和首份视角增量，等待所有旧鼠标按钮释放才能恢复世界动作；不会主动获得 OS 焦点。失焦、UI、恢复与正常点击分别检查。
- 换世界、离开游戏和阻塞模态清空临时 UI 状态。存档版本、生成版本、物品数量、任务完成及奖励语义不变。

## 玩家信息

- 快捷栏悬停有明确高亮，详情读取真实槽位、材质和工具／食物注册表；展示名称、数量／堆叠、用途、适用工具数据、耐久或食用效果。空槽不显示旧物品；点击只选择快捷槽。窄窗口浮层保持可读且不裁切。
- 任务区点击进入日志，列出真实可见任务、主线／可选分类、完成／可进行／前置未满足状态、进度与要求，允许选择并追踪可进行任务。进度来自 ObjectiveSystem；不从 UI 创建完成、奖励或改变任务依赖。
- 小地图点击进入 3D 地形详情。真实已观察地表材料和高程形成可旋转／缩放／平移的立体体素地图，显示玩家、已实际发现的地标、方位与比例。支持回到玩家位置及选择已知地表详情。
- 小地图保留 65×65 范围样本；详情独立覆盖当前渲染 chunk 范围，最多 129×129 列，4–32 m 自适应间隔。两入口沿用每次 195 列、30 Hz 的互斥查询预算，通过 World 对规范 4 m 列归档；不为地图生成或载入远处区块。未观察区保持未知，不用预测地形填满。地表投影使用真实高度，玩家箭头落在其 X/Z 对应的已观察地表；不是完整体素场景或地下洞穴模型。缓存、归档与迁移约束以[持久探索地图合同](adventure-exploration-map-contract-v1.md)为准。
- 复用现有像素 HUD 材质、物品图标与双语文本。关键关闭／返回控件在最小支持窗口与大字号下可达。

## 批次与验证

1. HUD 指针所有权、真实快捷栏详情和选槽。输入转移聚焦双配置、P11A、Release 客户端；当前窗口通过 Computer Use 检查 hover／点击／关闭。未验证项分开记录。
2. 真实任务日志与追踪。任务快照状态、前置／可选／已完成／空列表、世界切换和原目标保存语义；适用世界与资源检查、双语窗口。
3. 3D 地图与完整交付。投影／有限参数／排序／未知区域／真实采样预算及清理，真实窗口旋转缩放和关闭，当前 Debug／Release 客户端、完整世界和资源回归，默认关闭 HUD 的配对性能与打开页面的成本记录。只读 UI 不追加地形生成版本。

每批通过对应必要检查后中文本地提交。当前用户客户端和存档保留；独立后台工作包负责诊断。最终交付独立客户端、完整证据及真实能力限制，不把截图或注入当作正常交互。
