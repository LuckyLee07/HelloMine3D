# N11A/N11B 难度与有限重玩合同 v1

本文冻结 N11A 的世界级难度身份、集中参数、创建/暂停菜单事务，以及 N11B 的有限胜利后事件、
保存迁移、奖励幂等、确定性和预算边界。N11B 在 N11A 完成后作为独立伸缩项显式启动。

最后更新：2026-08-25。

## 身份与版本

- 难度档案 schema 为 v1，稳定数值 ID 为 Casual=0、Normal=1、Challenging=2；ID 不因显示
  顺序或后续本地化移动。
- 世界/玩家保存从 v9 升到 v10，新增必填字段 `difficulty_profile_version 1` 和
  `difficulty_id`。世界目录摘要、运行时 debug stats、性能 summary 和 soak summary 同时记录
  这两个身份。
- v1-v9 世界精确迁移为 Normal/v1；迁移不改变 seed、terrain generation version、已生成区块、
  玩家/目标/胜利状态或现有 actor。非法版本、非法 ID、重复字段和 v10 缺字段一律拒绝。
- 新世界在创建页明确选择难度，默认 Normal。创建命令一次性把选择写入初始 `world.meta`，失败
  不留下半创建目录。

## 集中参数

| 难度 | 玩家输出 | 玩家承伤 | 每轮生成尝试 | 世界/局部 cap | 掉落数量 |
| ---- | -------: | -------: | -----------: | ------------: | --------: |
| Casual | 1.20× | 0.75× | 8 | 8 / 3 | 5/4，向上取整 |
| Normal | 1.00× | 1.00× | 16 | 12 / 4 | 1/1 |
| Challenging | 0.90× | 1.25× | 24 | 16 / 6 | 4/5，向下取整且至少 1 |

所有值只从 `DifficultyProfile` v1 快照读取。玩家普通/武器攻击使用输出倍率；接触和投射物等
所有进入 `damagePlayer` 的伤害使用承伤倍率。自然生成只改变尝试数和 cap，不改变候选 hash、
生态选择、terrain seed 或区块生成。敌人掉落先按既有稳定表取基础数量，再执行有界整数倍率；
一次死亡仍只掉落一次，难度切换不得重算已经生成的物品实体。

## 运行时修改

- 暂停页显示当前和待应用难度；选择后只有显式 Apply 才提交命令。
- 合法命令只写入单个 pending 槽，不立即改变战斗、生成、掉落或持久字段；相同值返回
  `Unchanged`，非法值返回 `Invalid`，后来的合法命令覆盖尚未应用的旧 pending 值。
- pending 在世界恢复模拟后的下一个 fixed tick 开头原子应用并递增 application epoch。该 tick
  后发生的伤害、生成和掉落使用新快照；暂停期间没有 fixed tick，因此不会提前生效。
- pending 是瞬态命令，不进入存档；在应用前退出仍保留最后一次已应用难度。应用后正常保存、
  备份、重开和恢复都保留新难度。

## N11B 有限胜利后事件

- 只有世界结局为 `RewardClaimed`，即主线胜利奖励已经领取时，路标才开放回响试炼；试炼完全
  可选，不回退或替代权威胜利状态。
- 一个世界最多完成 3 次试炼。每次必须由玩家再次使用路标显式开始，包含两波固定守卫：

| 试炼 | 第一波 | 第二波 | 一次性奖励 |
| ---- | -----: | -----: | ---------: |
| 1 | 1 Stalker | 1 Brute | 2 铁锭 |
| 2 | 2 Stalker | 1 Brute | 2 铁锭 |
| 3 | 2 Stalker | 2 Brute | 2 铁锭 |

- 同时载入的试炼守卫最多 2 个；复用现有 Stalker/Brute、出生安全检查、死亡事件和难度伤害档案，
  不增加无限生成器、独立 Manager 或新 terrain 身份。
- 世界保存升到 v11，新增必填 `post_victory_event_version 1` 与
  `post_victory_completed_events 0..3`。v1-v10 明确迁移为 0 次完成；完成次数大于 0 时世界结局
  必须是 `RewardClaimed`。非法版本、越界值、重复/缺失字段和旧版本夹带字段全部拒绝。
- 路标块实体载荷升到 v2，保存当前试炼编号、波次和剩余守卫；v1 载荷读取为没有活动试炼。
  完成次数以世界保存为权威，因此破坏、替换或移动路标只能取消当前试炼，不能重置已领取奖励。
- 玩家死亡取消当前试炼并移除守卫，不消耗完成次数；再次使用路标从同一试炼第一波开始。区块
  卸载、保存重开和备份恢复按载荷恢复恰好剩余的守卫，不重复生成。
- 第二波结束只进入待领奖状态；背包容量足够且再次使用路标后，先发布已领取状态，再发放 2 个
  铁锭并递增完成次数。同一试炼只能领取一次，三次完成后所有后续使用都返回永久完成状态。
- HUD、世界列表、debug stats、性能 CSV/summary 和 soak summary 显示版本、完成数、活动编号和
  波次；Q1 比较把这些字段纳入身份，不同进度必须为 `INCOMPARABLE`。

## 最低验收

- 三档定义、稳定 ID、参数顺序和掉落整数边界通过；Normal 保持 N10 的既有数值行为。
- 新世界三档创建、目录显示、v9→v10 Normal 迁移、v10 往返、非法/缺失/重复字段拒绝通过。
- 暂停排队零提前变化，下个 fixed tick 一次应用；覆盖 pending、保存重开和 seed/terrain 不变通过。
- 同一夹具证明三档玩家输出、玩家承伤、自然生成压力和掉落数量形成单调且可解释的差异。
- Debug/Release VS2017/v141 定向目标、完整 Windows 门禁、当前身份 Q1 和 nominal/stress 短时
  soak 通过后才能把 N11A 标为 Done。R3 仍只记录部分自测，其余延后，不作为本批自动 PASS。
- N11B 还必须覆盖 v10→v11、路标载荷 v1→v2、死亡重置、中途重开恰好一个剩余守卫、三次
  固定奖励、重复使用不增发，以及破坏/替换路标不能重置完成数；所有守卫和奖励总数均有硬上限。

## 明确不做

本批不增加永久死亡、饥饿伤害、动态等级缩放、敌人等级、独立 GameMode、在线排行榜、成就、
无限任务、难度专属 terrain、按玩家位置回填结构、排行榜、赛季、账号成就或胜利后资源农场。
若后续改变任一 schema，必须新增版本和迁移，不得原地改写 v1 含义。
