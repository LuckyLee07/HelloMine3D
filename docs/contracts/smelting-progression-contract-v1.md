# 熔炉、冶炼与铁级成长合同 v1

> Architecture Lab 迁移说明（2026-08-31）：本合同冻结历史工程证据；文中 R3、真人和延期
> 描述保留当时语境，当前退出模型见 `docs/current/ai-assisted-gameplay-acceptance-v1.md`。

本文冻结 N2 的冶炼数据、熔炉容器、固定时钟、持久化和铁级成长边界。熔炉只通过
库存、方块实体、领域事件和目标系统的既有接口协作，不拥有玩家库存，也不允许 UI
直接改写产物或进度。

## 稳定标识

N2 只在既有编号尾部追加标识，不重排历史存档中的数值：

- 方块 `hellomine:furnace` 使用 `BlockId 19`；
- 材料 `hellomine:furnace`、`hellomine:iron_ingot`、
  `hellomine:iron_pickaxe`、`hellomine:iron_sword` 依次使用材料 ID 21-24；
- 旧世界无需提升区块格式版本；区块方块实体 v2 已能保存带版本的任意负载。

以后新增材料和方块仍只能尾部追加。改变现有编号、槽位含义或负载字段顺序必须先设计显式
迁移，不能静默复用 v1。

## 冶炼定义

基础定义位于 `media/smelting/Base.smelting`，由 Ogre 初始化前已经冻结的有效资源视图加载：

```text
# HelloMine3D smelting registry v1
smelt hellomine:iron_ingot
input hellomine:iron_ore
output hellomine:iron_ingot 1
ticks 100
end

fuel hellomine:coal_ore
ticks 160
end
```

注册表只接受规范化 ID、已注册且可堆叠的材料、正数且有上限的数量/时长，以及完整、唯一的
配方输入和燃料。错误头、缺字段、重复字段、重复配方 ID、重复输入、重复燃料、过大来源和
第二次冻结都会在发布前失败，失败解析不会产生半冻结视图。

`smelting` 是基础游戏独占资源类别。资源包 v1 不得覆盖它；若未来开放覆盖，必须先提升资源包
格式并定义已有熔炉和目标进度的迁移规则。当前基础清单共 43 项，其中严格玩法注册表为配方、
工具、音频、目标和冶炼五类。

## 熔炉容器和守恒

熔炉拥有三个独立槽位：`Input`、`Fuel`、`Output`。输入槽只接受存在冶炼配方的材料，燃料槽
只接受已注册燃料，输出槽拒绝任何玩家插入。玩家到熔炉的转移先从来源槽扣除，再更新方块
实体；更新失败会把同一物品退回玩家。熔炉到玩家的转移先检查实际容量，容量不足时不修改
任一侧。

破坏熔炉会移除方块实体、关闭正在查看该位置的界面，并把三个槽中的非空堆分别生成到世界。
进度和剩余燃烧时间不是物品，破坏后不会转移。无效或版本不支持的负载不会被解释为有效物品。

UI 只读取熔炉快照并提交转移命令。快捷栏物品会按注册表自动路由到输入或燃料槽，点击熔炉槽
只执行领取；进度条和燃料条来自保存状态，绘制本身不能推进模拟。

## 固定时钟和暂停语义

世界模拟为 20 Hz。铁矿配方需要 100 tick（5 秒），一份煤矿燃料提供 160 tick（8 秒）：

- 只有已加载区块中的熔炉由 `World::tick` 推进；
- 暂停状态不调用世界固定 tick，因此进度和燃料同时冻结；
- 区块卸载或进程退出期间不累计离线时间，重载后从精确保存值继续；
- 没有输入、配方不匹配或输出无容量时，进度和燃料同时暂停；
- 燃料耗尽会保留部分进度，补充燃料后继续；
- 完成一次冶炼时，输入扣除、输出增加、进度归零和方块实体更新先原子完成，随后才发布
  `SmeltCompleted` 事实事件。

这些规则禁止通过暂停、卸载、装满输出、重复打开 UI 或失败保存复制物品。

## 方块实体负载

熔炉类型为 `hellomine:furnace`，负载格式固定为：

```text
v1|inputMaterial,inputAmount|fuelMaterial,fuelAmount|outputMaterial,outputAmount|
progressTicks|burnTicksRemaining|burnTicksTotal
```

空槽使用 `0,0`。解析要求恰好七段、整数完全消费、材料/数量与专用槽匹配、进度小于当前配方
时长、燃料剩余不超过总量。未知版本、工具材料、错误槽位、负数、越界值和与当前注册表矛盾的
状态全部拒绝。既有区块事务、备份和恢复机制负责发布该负载，N2 不创建旁路存档文件。

## 铁级成长和目标

基础工作台新增三张配方：8 石头制作熔炉，3 铁锭加 2 树皮制作铁镐，2 铁锭加 1 树皮制作
铁剑。铁镐为镐类 3 级、6 倍采集速度、64 耐久和 4 点攻击；铁剑为武器类 3 级、80 耐久和
7 点攻击。只有被演员系统接受的攻击才扣除一次手持工具耐久。

N2 在 N1 的 11 项定义后追加 5 个可见必做目标：制作熔炉、放置熔炉、冶炼 5 个铁锭、制作
铁镐、制作铁剑。目标类型新增 `smelt_item`，只消费成功发布的 `SmeltCompleted` 事件。基础
目标现为 16 项、9 种类型；`AlphaJourney` 仍只映射旧十步和低 10 位兼容标志，不改变 v4/v5
迁移语义。

soak、受控崩溃和干净包保持通过。真人熔炉 UI、攻击手感和画面签收继续后置到 N6/R3。
