# 高地工位机器视线 terrain v31 合同

V08c属于已授权的[视觉精修Goal](../current/visual-experience-polish-goal-prompt-2026-09-28.md)。
本合同约束高地工位的单格遮挡修复；工程与限定实机结果记入[执行记录](../reports/visual-experience-polish-execution-2026-09-28.md)。

## 变化与保留规则

- 追加`HighlandWorkshopSightlineTerrainGenerationVersion=31`，新世界默认v31。
  显式v1–v30输出、已保存区块、玩家改块及旧世界首次生成的未来区块保持原版本规则；
  不迁移、不回填，也不修改用户现有世界。save12、map4、settings11、方块／物品ID保持。
- 在[原v29露天工位](workshop-courtyard-v29-contract-v1.md)上，仅将Highland样式的
  局部`across=2, depth=0, level=1`由Stone改为Air，使斜向接近时破碎机不被前角墩遮住。
  左右镜像均使用同一局部坐标规则；v29上两层净空保持，旧v22–v30工位的三处低角墩保持。
  林地、河岸、Open及其他块位不变，不移动机器或改变主地标。
- 继续使用[原v22工位](adventure-regional-workshops-v22-contract-v1.md)的候选、选址、样式、
  镜像、同区块限制、九格地面、到机器的两格净空路径、干燥／坡差与落地安全检查。
  林地空箱子、河岸空熔炉、高地空破碎机的位置、类型、初始payload和使用语义保持；
  主建筑、布局、入口轴、地点奖励、矿物、树来源避让与洞口／其他结构退让保持。
- 每区块地点计划最多四处、每工位最多36个块位写入及一个空方块实体；
  不增加邻块加载、地形查询范围、缓存、每帧工作、资源或渲染节点。
  已保存机器payload、玩家放置／拆除及保存重开按既有存储路径恢复，不重新填机器或角墩。

## 必要验证与证据边界

1. 当前`HelloMine3DWorldRuntimeSmoke`以`HELLOMINE3D_WORLD_SMOKE_FOCUS=WORKSHOP_SIGHTLINE`
   分别运行Debug／Release：蓝图全部样式与两侧镜像只改变授权一格；seed42三类真实工位
   的计划、布局、奖励、完整区块id／metadata和实体payload对比，v30→v31仅高地该角墩不同；
   正反生成一致，九格地面及机器路径有真实支撑／净空。保留v30角墩Stone的故障对照。
2. 检查真实生成机器的打开、空载、使用和payload保存；高地破碎机沿原接口处理并取回产物。
   玩家在角墩位置放置后保存重开仍保留改块，拆机／拆块后再次重开不回填。
   v30存档重开后首次加载尚未生成的高地工位，与显式v30完整方块／实体一致，原玩家改块保持。
   新世界默认、正常出生、保存和重开身份严格为31。
3. 保留显式v22的`ADVENTURE_WORKSHOP`与显式v29的`WORKSHOP_COURTYARD`回归；
   运行Release完整WorldRuntime和正常Debug／Release客户端构建。历史版本专项继续冻结其
   原版本，不把新默认31改写成旧专项的默认版本，也不放宽块位、净空或保存门槛。
4. 修改前后生产`T0-SURVEY`的旧v1–v30 `samples.csv`／`chunks.csv`逐字节一致；
   新v31纯地表列除版本字段外与v30一致，实际工位区块差异另按授权块位核对。
   记录源码、二进制、命令、版本范围及原CSV身份；抽样不代表穷尽所有坐标。
5. 保留当前冻结seed42高地地点同机位前后完整原图：地标锚点`(-36,135,11)`、工位
   minimum`(-40,5)`／baseY134、机器`(-39,135,7)`；检查前角墩消失后真实机器可辨，
   主建筑、入口与其他工位表现保持。记录实际world版本、相机、配置和来源，查看原图，
   精选2–3张升级后原PNG。固定诊断到达不证明普通发现、步行进入或使用；这些仍按V08补验。

严格配对性能为`DEFERRED_BY_USER`；崩溃、明显卡顿、无界增长、容量与存档问题仍须处理。
不设置人工审美确认或独立试玩签字；本单格工程／诊断证据不关闭V08整体或完整Goal。
