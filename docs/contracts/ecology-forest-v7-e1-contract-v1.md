## 本轮范围

- 新增 terrain v7，仅新建世界默认采用。v1–v6 的地形、树木、植物及存档读取保持原样；
  已生成区块和玩家编辑绝不重生覆盖。
- 仅调整森林生态的世界坐标树木分布与林下草/花疏密：轻林、密林要有可辨的疏密层次，
  在同一林区内能看到树群、较疏的通行带和自然边缘。保留用户已认可的 v6 方块橡树树形。
- 高度、生态边界、海岸、水系、洞穴、矿物、其他生态树木、地点/战利品、方块身份、
  材质和渲染均不在 E1 改动范围内。E2 及以后再处理地表/岸线与水系。
- 代码触点限 `TerrainGenerator.h`、`ClassicOverWorldGenerator.cpp`、必要的聚焦测试、
  v6 兼容快照及对应验证脚本计数。根据用户本轮新要求，视觉捕获脚本
  `tools/capture_visual_macos.py` 与 `tools/package_macos_release.py` 只增加复用和原位刷新
  同一个未验收客户端包的模式；文档触点限本合同、
  E1 执行报告、当前账本与当前代理工作流。
  验收原始媒体和包留在本地 `build/`。

## 退出条件

1. v7 的森林树木/林下植被由 seed 与世界坐标决定，不依赖区块加载顺序；负坐标和
   跨区块树冠连续。v1–v6 生产区块指纹不漂移；v7 的高度、生态、洞穴、矿物及
   地点/奖励规划仍与 v6 一致。
2. 聚焦统计展示轻林/密林树干及草花密度、局部疏密差异和跨区块边界，不能只调单一
   全局概率来宣称“生态更丰富”。出生可用木材、基本资源和地点路线不能退化。
3. 本机适用的 Debug/Release 自动回归与资源/存档门禁通过；对 v6 同机同设置采样
   森林常驻和快速流送性能，P95/P99 帧时间不超过 v6 的 1.10 倍，记录 mesh、
   buffer 和加载数据。失败保留原始数据，不放宽门槛换 PASS。
4. 独立包带 SHA-256；同 seed/机位/画质/时间的 v6→v7 原图与正常菜单新建、林中
   行走/转头、采木、保存重开证据分别交付。无法执行的输入项标 `BLOCKED`，
   不以固定相机截图替代正常玩法。
5. 向用户交付包、画面/视频、逐项 PASS/FAIL/BLOCKED 和剩余风险，等待明确验收。
   只有验收通过才仅暂存本轮文件，做一个本地提交并核对内容与已验收包一致。
