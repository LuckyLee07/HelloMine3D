# 冒险世界 B5 持久探索地图合同 v1

用户已授权[完整体验目标](../current/adventure-experience-goal-prompt-2026-09-22.md)。
本合同限定持久地图的数据来源、容量和失效方式；B5a 已完成有界观察数据层，
B5b 已完成独立文件、世界备份与真实世界保存接线。B5c 的个人标记值层、文件 v2、
World 命令、文件 v4 的任务绑定及平面地图页面已接入，实际窗口操作仍待验收。
这些工程结果不代表玩家已能在界面使用持久地图。进度见[执行记录](../reports/adventure-experience-execution-2026-09-22.md)。

## 数据真值与容量

- 只接收玩家世界已加载区块中的 `SurfaceMapSample`。锁忙或缺失时保持未知，
  不能调用地形生成器、同步加载远区块，或用任务位置反推出未到达的地形。
- 归档按世界坐标每 4 m 一个地表单元；32×32 单元为一页，负坐标采用数学向下取整。
  已知空列与未知列不同。再次观察同一单元可刷新真实方块编辑后的高度和材料。
- 最多 4096 页；包含容器节点开销的内存保守上界小于 16 MiB。达到容量时保留已有记录，
  拒绝新增页并向界面返回明确满额结果，不循环淘汰玩家未备份的探索历史。
  持久文件最多 64 MiB；超过容量应拒绝保存并维持旧的有效文件。
- 已探索归档是地表资料，不等同视线可见性或地下洞穴地图。临近玩家的现有 1／2／4 m
  局部样本仍优先绘制，可在远区平面总览使用 4 m 归档；未知区域持续遮蔽。

## 持久化与世界边界（B5b 已实现）

- 使用世界目录内独立版本化地图文件，不扩大当前 64 KiB 的 `world.meta`。
  世界存档 v12 与地形 v22 不因地图表现自动改变；旧世界地图默认为空，首次真实观察后再写。
- 文件含格式版本、世界 ID、种子、地形版本、页数／标记数、长度和校验。
  载入只接受匹配当前世界身份的有界完整文件；重复页、非法材料／坐标、截断及校验错误
  退回空地图并提示，不使世界目录或主存档无法载入。
  地图文件 v2 追加有界标记记录、下一个稳定 ID 与追踪 ID；v3 再追加至多一个由真实
  方块放置或界石交互发现的任务地点。读取 v1 时标记／地点默认为空，读取 v2 时地点
  默认为未知。v4 追加独立的任务绑定界石（至多一个）；v3 仅有发现记录，
  不自动将其升级为活动任务绑定。下次真实写入升级为 v4。每个标记的 ID、UTF-8 名称、单一基地与已探索
  位置必须有效；任务地点仅存正高度的世界坐标。存储 API 要求显式传入标记与地点，
  绑定地点也须显式传入，避免保存地表时误清空已有导航信息。
- 发布沿用 `StorageTransaction` 的候选写入、持久刷盘、完整校验、原子替换与失败隔离；
  `WorldBackup` 的创建、验证、恢复和回滚必须包含可选地图文件。地图保存失败不得伪称
  世界完整保存，备份不得遗漏存在的地图。容量上限和备份总量需配套检查。
- 切世界、退出和恢复备份清除旧世界内存；页内记录从实际重新观察更新，
  未重新加载的远区保留上次已知地表而不伪称当前状态。
- 生产 `World` 每 10 个固定 tick 最多查询玩家周围 81 个 4 m 地表列；锁忙则跳过，
  只接纳驻留区块的真实结果。观察改变时才发布地图，顺序为区块／元数据、地图、备份。
  退出时同样保存未写出的观察。损坏或错身份文件隔离为同目录 `.corrupt.failed`；
  隔离槽已有文件或路径不是普通文件时不覆盖它，并明确报告保存失败。
  `ExplorationMapStatus` 向界面提供当前会话的损坏／身份重置原因、隔离失败、保存失败和
  满额状态，不将 stderr 当作玩家反馈。成功重试清除保存失败，重置提示保留本会话；
  新世界或健康重开使用新状态，不污染其他世界。

## 地图导航与界面（B5c 部分实现）

- 个人标记最多 64 个，支持创建、重命名、移动、删除和跟踪；满额有明确反馈。
  出生／基地位置以玩家确认的保存信息显示，营地／路标只在实际发现后显示。
  B5c 已建立 `ExplorationMarkers` 值层、兼容 v1 的文件 v2 和 World 命令；稳定 ID、
  单一基地、单一追踪、UTF-8 名称和容量边界均可验证。World 创建或移动标记前必须确认
  该 4 m 单元已探索；如尚未归档，最多向驻留区块查询一个真实列，锁忙或远区仍拒绝。
  玩家地图页已接入创建、重命名、设基地、追踪、移动和确认删除，标记在已探索的平面图
  显示；小地图显示当前追踪点的方向和距离。普通输入、紧凑布局和保存重开的界面回路
  尚未实机验收，不把编译视为已证实可用。画布、列表和新增入口共用稳定 ID 与名称
  缓冲的选择更新；删除／切世界清理。底图北向，玩家箭头与小地图按同一 yaw 计算方向。
  地图异常在小地图显示标识，在详情页展开原因；备份入口先按原正常关闭流程保存并
  打开对应世界备份列表，失败则保留会话并说明原因。实际恢复仍需现有确认且回滚整世界，
  不静默覆盖地图、删历史或绕过保存失败。
- 已知任务目的地提供方向和距离；目标未发现或没有权威坐标时不揭露生成结果。
  当前仅当玩家实际放置或使用的界石已有已知坐标、且任务为对应仪式／防守阶段时，
  平面图才绘制任务位置与方向／距离。早期寻找、修复等无固定坐标目标不推导生成点。
  玩家放置界石更新最近发现地点；成功激活／继续事件或恢复真实事件锚点时，
  同时记录独立任务绑定。导航优先绑定，其次运行时事件锚点，只有任务尚未激活时
  才回退到最近发现。普通新放置不能覆盖任务绑定；拆除时分别清除匹配的记录。
  两记录随 v4 地图保存、备份和恢复，远离所在区块重开仍可导航。旧 v1/v2 没有地点，
  v3 没有可靠任务绑定，无法凭生成器或既有任务进度补造；真实交互／事件恢复后才获得。
  多个界石的发现仅保留最近一个，后续地点列表须另行有界设计。
  玩家标记导航使用北向八方位与地表水平距离；极端旧存档坐标先扩宽再相减，
  不产生溢出或虚构路径。
  平面总览只显示归档内真实地表，65×65 屏内、可平移复看和点选材料；
  支持 4／8／16／32／64 m 每格缩放。缩小时每格从实际记录的 4 m 单元选离中心最近的
  代表样本；有任一实际记录的格才显示已知，且标记使用代表样本的真实坐标，未知区域
  不补生成预测。总览查询只扫描视口覆盖的现有归档页，不读盘、不加载区块；临时结果
  至多 4225 格。现有局部立体视图暂仍使用驻留样本，后续完成持久数据共用与已知任务导航。
  视图切换保持玩家当前位置及操作反馈。
- 普通输入检查离开后复看、重启、切世界、标记编辑、追踪返家；诊断坐标镜头、
  预置存档和自动测试只能证明对应工程语义，不能代替普通探索。
