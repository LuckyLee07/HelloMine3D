# 视觉升级：驻留水深与岸线 v1

用户的综合视觉 Goal 第 3 阶段；不改变 terrain v1–v12、存档、流体和碰撞语义。

- 网格输入只观察已驻留方块。连续水柱深度最多 8 格，8 格以上按吸收饱和处理，
  不调用生成器预测水底、不加载邻区块。每个带水底边界的 18×18 快照列最多追加 7 次查询。
- CPU 快照保存每格的有界水深；水面每个角取相同世界坐标的四列平均，岸线权重只由同高度
  的实体岸壁产生。负坐标、区块/section 接缝共享采样规则。
- 水材质复用此前未使用的 repeat UV 携带水深/岸线，顶点 stride 仍为 32 字节；
  地形/植物/透明方块的纹理坐标不变。只改表现，不写回权威数据。
- 修改水底时，最多检查其上方 8 格的驻留水，按既有队列使受影响 section 的快照 revision
  失效；不扩大 worker、上传或构建预算。普通岸边编辑沿用一格 halo 的失效规则。
- 吸收色和透明度取决于水柱深度；距离仅用于雾，视角仅用于反射。岸边少量波纹不改变
  顶点高度，水波仍取世界坐标，并使用连续时间；关闭大气表现时保留稳定的简单水面。
- 水面细纹增加顺岸风驱漂移：同一角点的四个驻留样本构成实体岸法线，将固定微风投影到
  岸线切向，并按实际水覆盖衰减。只复用快照，不追加查询或加载；水材质未使用的 atlas UV
  携带二维漂移，stride/面数不变。双相位交叉淡化保证循环无跳变，最大亮度调制 3.5%，关闭时静止。
  E5 水面本身等高且无水文流向，本项表达风驱表面运动，不宣称河流下泄模拟或改动水体物理。

- 水下相机每帧最多读取两个已驻留方块，水面下 0.05–1.0 m 区间连续增加水介质雾与轻微曝光衰减。
  地平线背景使用同一介质色，避免驻留地形之外露出空气色亮带；色板在顶层水块底部达到完全浸入，
  与更深水块连续。此过渡只依赖深度，无逐帧积累，不随帧率变化。
  空气、未知块和关闭大气表现沿用原环境；不修改世界时间、水体色板、物理或保存状态。
- 相机穿过水面时，水上/水下表层颜色在相对表面高度 ±0.20 m 内连续混合。
  为避免 0.1 m 近裁剪面将深色水面切成屏幕横带，相对高度 ±0.10 m 内表层覆盖为零，
  水上至 0.35 m、水下至 1.0 m 平滑恢复原覆盖；水下区间较长是因为表层覆盖大部分天空。
  这是穿越边界的局部抗裁剪处理，区间外仍按真实水深吸收；既有驻留介质雾继续表达浸入。
  只用现有相机/世界表面坐标，无新采样、材质接口或顶点字段，关闭波浪时同样消除横带。

- 陆地湿润过渡只作用于不透明立方体的派生网格明暗：每个世界角点检查四个相邻柱在角点高度及其下方
  的驻留水，最多衰减 18%，沿一格岸面插值回干燥外观。不新增几何带、材质、shader 参数或顶点字段，
  不修改存储的阳光、方块光、AO、碰撞和存档。透明块、植物、物品与水材质不走此分支。
  快照已有复制循环顺便记录是否含水；无水快照直接跳过。每个 builder 以 17³ 字节缓存角点结果，
  每角点最多八次快照读取，不访问 World。共享世界角点规则保持区块与竖向 section 接缝一致，
  普通岸边/水块编辑沿用既有 halo 失效；greedy 合并继续检查最终明暗的可重建性。
  低档及关闭大气动画时保留静态湿润过渡；本项不代表湿度模拟或随时间干燥。

验证：定向水深/跨 section/负坐标/编辑/未知邻域及不生成测试；MeshDirty、完整
WorldRuntime Debug/Release、资源正反例、GLSL 深度与连续时间/跨区块实测；水上/水下、
浅滩/深潭、岸边编辑及低档窗口观察；同条件静态与移动三轮性能。静态 GPU 样片不替代实机。
