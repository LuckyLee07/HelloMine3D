# 地标建筑与地形衔接 terrain v14 合同

本批承接用户已批准的综合视觉升级与地形多样化优先级。范围是三类既有地标的轮廓、入口和落地关系，
不改 v13 沙丘、岩台、湿地等地貌参数。2026-09-19 开始；基线 `f0a03c0`。

- 营地采用错层木板棚、木柱与开放院落，入口留出连续空间；遗迹采用残墙、石拱与有支撑的玻璃；
  路标采用收分石座和中心竖向轮廓，保留可见核心。全部是可交互的真实方块。
- 新增 terrain v14，旧 v1–v13 生成、已保存区块和世界身份保持，world save 仍为 v12。
  地标类型的 cell 分布继续采用原 v5 盐流；候选筛选可以因落地/入口约束改变。奖励表、箱子位置、
  核心及矿物数量保持；同一候选沿用旧奖励哈希版本，建筑材料数量可变。
- 候选只读纯高度/生态规划；完整 footprint 起伏不超过两格，基础下探两格。前向入口至少有一格
  高差不超过一格的干地连接。每类保持原水平范围和最高点，每个 cell 最多一个、每块最多四个计划。
- 树冠与建筑避让使用有界 halo 的相同世界坐标计划，不加载邻区块，不截断既有生成树冠制造悬空叶片。
  新版逐格唯一投影，上限为路标 225、遗迹 729、营地 792 次写入；旧版投影路径保留。
- 检查：实现前冻结 v2–v13 八 seed 三类地点的计划、实际区块与箱子指纹；旧版逐字节对照，
  v1 及基础地形沿用相关兼容回归。新版验证三类地点可获得、入口/支撑、矿物/奖励数量、加载顺序、
  跨区块投影、树木避让、保存编辑与重开。双配置构建、聚焦及完整 WorldRuntime 必须通过。
- 复用隐藏且不激活的工作包，先看当前 v13，再看 v14 同类三 seed 原图、昼夜及连续相机画面。
  保留失败；诊断画面不代替玩家移动。受影响地标常驻/快速流送至少三轮对照，P95/P99 中位数比
  不超过 1.10；报告生成成本、网格和驻留变化，执行结构相关 Q3 检查。
- 交付干净包、当前证据和中文本地提交；正常持续输入按用户决定暂缓，不重复索要授权。
