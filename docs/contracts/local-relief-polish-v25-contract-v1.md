# 局部地形精修 terrain v25

V03 在既有区域骨架和水系上增加数米至数十米的路线变化。生产入口为 v25 的纯列规划，
不改变渲染网格来伪造地貌；完整 V03 仍须普通路线与三种子、八生态整合证据。

- 追加 v25，仅用于新世界；显式 v1–v24 的高度、方块、装饰及未来区块生成保持原规则。
  保存格式 v12、材料／生态 ID、奖励经济保持。已有区块和用户客户端不迁移。
- 用有界世界坐标锚点取得既有真实坡向，在坡面组织支脊、浅槽／鞍部与局部落脚平台；
  形状在边缘连续淡出，单列位移最多 6 格，不依赖区块加载顺序。
  水下、岸边低地及河湖主体不改高度；水系附近逐渐减弱地貌位移，保留连贯排水。
- 材料依据坡度、坡脚／沟槽沉积及已有生态选择裸岩、砾石或土面，保留雪线、湿地、沙丘及水岸路径。
  草林过渡复用现有混合区域场，不以大片纯换色替代地形变化。
- 实际方块、公开高度、出生、洞口、树根／地被、建筑规划消费同一版本高度。结构原有地基与
  通行检查继续生效；不能用扩大树冠覆盖或埋藏入口掩盖缺陷。
- 规划查询仅用固定邻域和有上限的纯值缓存，完整校验 seed 与有符号坐标；无 World／Chunk 指针、
  无递归生成或邻区块加载。signed 极值计算用 double／int64，不能整数溢出。

## 修改前确定的检查

1. 用修改前 Release 生产二进制冻结 v24 T0 八 seed 列／区块输出；v1–v23 复用 V02 已冻结且逐字节
   相同的生产基线。候选重跑逐版本核对，不更新预期消除漂移。
2. 新版三冻结 seed（42、20260807、239701883）宏观 ±2048 步长16、出生 ±96 逐格、正负边界
   与 signed 极值：位移不超过6，高度仍1..176，受保护水列不变，抽样相邻差最大8，
   普通宏观样本至少95%相邻差不超过2。统计只证明边界，不替代可见效果。
3. 支脊、浅槽、平台均有实际非零变化；连续斑块不变成逐格椒盐。核对独立实例、跨线程、
   不同 seed 插入查询及反序生成。当前版实际方块与公开列一致，植物有支撑，建筑／洞口按新高度规划。
4. 双配置定向及必要完整世界回归、客户端构建；旧世界保存身份、新世界默认版本、出生安全和
   资源／地标／地下回归必须成立。失败如实保留，不删测试换 PASS。
5. 复用 V05 岩坡机位（seed42，40.5/92/56.5，旋转0/0/0，time7000，FOV90，高阴影、兼容，
   1280×720点、DPR2）作为第一处固定对照；新高度先核对避免相机埋地。
   连续普通路线、三种子多生态和河谷／记路点在 V03 整体收口时补齐，不能由局部原图宣布全部完成。
   每轮保留2–3张升级后游戏原图及版本说明，人工核验与严格配对性能按 Goal 延期安排。
