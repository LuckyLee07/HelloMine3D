# 冒险目的地 terrain v20 合同 v1

状态：B4a 两布局工程实现；区域接近线索、三套可建造材料搭配、普通探索和性能仍待
B4 后续批次完成，不能以本合同宣称整个 B4 已验收。

## 生成与兼容

- 新世界使用 terrain v20，world save format 继续 v12。已记录的 v1–v19 世界保持原
  terrain 身份、地点候选、蓝图、旧区块及未来未生成区块规则；不触碰玩家编辑的区块。
- v20 沿用 v19 的地貌、高度、区域及地标候选流。三类地点在同一个候选位置和占地内，
  使用 `selectionHash` 的固定位选择布局 0／1；类型和可交互对象 ID 不变。箱子位置、
  路标核心坐标、铁矿／煤矿数量及旧奖励哈希保持。没有额外随机数流、同步区块加载
  或新持久字段。
- 建筑仍以确定性纯规划和唯一逐格投影完成；营地最多 792、遗迹 729、路标 225
  个候选写入，跨区块与加载顺序一致。地点树冠避让使用原有有界 halo。新增地标
  不能重排其他世界版本的计划键或种子结果。

## 两种可进入空间

- 营地：原错层双棚院落与带有可步行阶梯、开放瞭望台和低矮侧棚的营地；箱子都位于
  开放主通道一侧，不因新布局增加领取次数。
- 遗迹：原前门石拱与带侧室、破损院墙的开放庭院；中央箱子和四块铁矿可进入、可采。
- 路标：原后扶壁石座（前方腾出立足点）与四角瞭望石柱／后横梁的开放石台；核心
  均在相同坐标，前方保留两格净空的接近位置。

两布局须在实际种子中均可选中，不以单纯镜像、改色或额外宝箱代替空间差异。
布局 1 的抬高部件有地面支撑，玩家可从外部进入主院落；普通输入与连续画面
在 B4 集中实机检查。

  每格生产区块与蓝图一致、正反加载一致、两格入口、核心／箱子／矿物数量、
  箱子真实 payload；同时执行 v14 回归。
- 新版完整 WorldRuntime、v1–v19 保存与生成兼容、正常创建／改块／保存重开，

  审美单独记录；无窗口聚焦只证明工程行为。
