## 颜色与回退

新增独立 legacy 和 linear HDR 模式，旧设置迁移 legacy，切换管线需重启。legacy 的后处理 Off 和 On 保持。HDR 始终执行固定曝光和显示转换，Off 仅关闭可选后处理。全部场景类别进入同一线性域，Alpha、深度和数据纹理保持原语义，HUD 在主窗口末绘。

浮点 RTT 必须实际创建并证明保留大于 1 的信号；格式静默降级、能力不足和创建失败完整退回 legacy。声明的坏资源和 shader 编译失败明确报告，不混入能力回退。切世界、缩放、销毁保持有限资源与完整状态恢复。

## 可编辑形状

旧 shape v1 和既有 ID 保持。v2 仅单格内复合盒，盒数和几何量有上限、边界按 1/8 m 离散。新 StoneStep 和 StoneWindowFrame 的 metadata 0–3 保存四向，旧 metadata 不重解释。形状、碰撞、选取、反馈、手持和掉落一致；窗洞可选中后方，台阶有真实高度。部分盒不被当作整格遮挡或实心层，首版局部光传播仍按格处理。
