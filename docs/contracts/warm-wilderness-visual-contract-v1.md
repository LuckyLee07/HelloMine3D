# 暖野视觉第一版合同

2026-09-12 用户授权实施 2026-09-10 的自然温暖视觉方案。起始 commit `a18ba59`。
当前平台为 macOS；Windows 专属构建不属于本轮已执行声明。

## 范围

- 新的草/土/石/木/叶图集内容及现有生态槽位；HUD、主菜单及共享控件主题；地形暖光冷影。
- 实机固定条件对照、受影响自动检查、针对性性能与干净 macOS 包。
- save v12、terrain v1–v5、settings v8、方块/物品身份、五槽背包、网格布局、AO 和玩法真值不变。
- 旧世界显示新材质，但不重建其保存数据。树形、水系、地形分布和新方块不在范围内。

## 资源与表现

材质仍使用 v1 的 256×256 / 16×16 图集及 120 项语义布局；所有透明类别、空槽和分面继续验证。
新母版由 imagegen 生成，确定性采样、Alpha 约束和生态派生属于资产构建步骤，禁止手改运行图集。
未改造的图标从已验证的前版图集母版原样保留，来源及重建入口须可追溯。

本批有意更新基础资源的颜色参数值和地形显示合成；V10B1 的参数格式、边界与启动失败语义仍有效，
其历史“默认像素一致”结论不适用于本批的新外观。headless 的兼容默认值不改变。
普通、透明和植物以及开启阴影后的材质必须共同消费新增光色接口。
地形暖冷调制只能作用于已有光照结果，不新增世界光源或修改光传播；夜间不提亮成白天。
不增加顶点属性或新离屏渲染目标。阴影/后处理的 Off 与能力回退继续有效；大气强制回退关闭新光色调制。

菜单静态背景属于界面艺术资产，不是当前运行存档，不把主菜单画面作为实机世界证据。
F1 保留调试信息入口。默认 HUD 聚焦当前目标和生命/物品栏；教程、额外目标和所有必要反馈须可访问。
中英文、0.85/1.0/1.25 字号下检查主要菜单、目标 HUD、制作/容器和暂停。

## 验证与性能

- 图集尺寸、120 语义、136 空槽、所有 Alpha、未改图标、分面/图标映射和确定性文件重建。
- shader 有效接口及缺失/陈旧覆盖负例；macOS 受影响客户端和测试目标 Debug/Release。
- 涉及世界环境值时运行现有环境及完整世界回归；MeshDirty、资源包、UI/设置定向回归。
- 固定 seed 20260807、机位、1280×720 逻辑窗口、FOV90、RD8、时间和档位；记录 Retina 物理尺寸。
  相同运行诊断启动时刻取 5s/10s 原图；不改世界时间推进以凑图。
- Off/Off、Medium/Off、High/On（方向阴影/后处理）各三轮性能，5s 预热、30s 采集。
  各档三轮 frame P95/P99 的中位数均不超过本轮原版对应中位数的 110%；几何/流送字段单独核对。
  失败保留，只有查明运行干扰或代码修正才追加可比较样本，不事后放宽护栏。
- 捕获脚本可使用明确标记的强制机位/HUD 夹具；这些只构成开发诊断对照，不冒充正常玩法。
  正常菜单/设置/世界操作另从干净包通过 Computer Use 检查，说明实现者自测与独立验收的区别。

进度与实际结果见 [执行记录](../reports/warm-wilderness-implementation-2026-09-12.md)。
