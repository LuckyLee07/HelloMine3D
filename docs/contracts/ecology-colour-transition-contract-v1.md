# 生态颜色过渡 r33

用户持续视觉升级中，地形多样化优先。r32 原图显示岩台与林地草面存在颜色硬边；本批只改变派生
植被颜色，terrain v15、save v12、高度、方块、树形与水体生成保持。

- `SectionMeshInput` 捕获世界对齐的 4 米颜色网格；每段 81 次纯生态查询、25 个气候值，
  半径 8 米三角核平滑。不访问或加载邻区块，不使用相机、时间、随机状态或可变缓存。
- 草顶、草侧绿色部分、橡树叶和草丛共享干暖/林湿参数；海岸保留冷色，森林保留深绿，岩台保留
  干暖色。湿地叶片同路；泥土、穗头、花朵、水、矿物、HUD 和手持物不接入新颜色。
- 保留生态 tile 整数索引和三种坐标变体。uv0 原本未使用的小数部分以内部 .25–.75 区间携带
  两个颜色参数；uv1 重复坐标、AO/光照和 32 字节顶点/4 字节索引不变。greedy 合并同时要求
  重建内部颜色采样，不能因光照相同而吞掉颜色变化。区块共享角点值一致。
- 普通/阴影、atlas/array 路径从同变体的草甸参考 tile 采样，再应用连续颜色；不改变 Alpha。
  `surfaceLightingStrength` 关闭时继续采样原生态行，以保留兼容回退。此合同修订旧生态合同
  中对 uv0 小数的用途；tile 选择合同 v1 和世界生成身份不变。
- 验证：纯场的接缝、负坐标、边界幅度、采样上限、加载顺序与整数极值；生产快照/网格检查，
  双配置客户端与受影响回归；实际 GPU 四路径、土色/透明遮罩/兼容/阴影一致和旧 shader 负例；
  同机位林缘/草甸/湿地前后原图及连续帧，受影响常驻/流送三轮性能。失败保留，不降低 1.10 护栏。

当前为实施中；不将诊断镜头等同正常连续行进，不借本批宣称综合 Goal 已完成。
