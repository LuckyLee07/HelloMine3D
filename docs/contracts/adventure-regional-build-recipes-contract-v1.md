# 冒险世界区域建造配方合同 v1

状态：B4 区域材料的正式制作与建造路径已接入；terrain v22 地点建筑示例已有工程实现，
普通探索、画面及性能仍待 B4 集中验收。本合同不宣称整个 B4 完成。

## 正式配方与用途

- 林地储物：2 苔石、4 橡木木板、1 林地土制作 1 箱子；苔石／林地土在林地采集，箱子可放置并储物。
- 河岸窑炉：4 黏土、4 砾石、1 淤泥制作 1 熔炉；三种地表材料在河岸／湿地采集，熔炉可放置并冶炼。
- 高地破碎：4 砾石、2 石头、2 橡木木板、1 铁锭制作 1 手摇破碎机；高地采石，石头经既有冶炼取得，铁锭仍是必要进度门槛；机器可放置并加工。

三条均为工作台 3×3 的正式配方，保留旧箱子、熔炉和破碎机配方。新配方只增加获得途径，输出继续使用既有 Material／Block ID、物品栈、机器和容器语义；不新增 world save、terrain、目标定义或资源包协议版本。旧存档已有物品和已学配方 ID 保持，新配方随真实材料取得进入既有配方发现流程。制作必须走原子预览／提交，材料与产物守恒；放置和保存重开保持既有块实体规则。

## 验证边界

`ADVENTURE_MATERIAL` 覆盖六种地表材料的采集／放置，以及三条新配方的正式解析、工作台制作、材料扣除、产物放置与重开。`HelloMine3DRecipeSmoke` 检查旧配方与新内容并存、经济链无循环／净增漏洞；`HelloMine3DResourcePackSmoke` 与资源门禁检查正式资源加载。生成场景中的材料可达性、建筑示例、普通玩家发现配方和地点后带回建造，另在 B4 集中实机中验收；诊断库存不冒充普通采集。
