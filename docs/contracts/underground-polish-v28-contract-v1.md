# 地下形态与铺地精修 · terrain v28

## 范围与身份

- 在 v27 之上追加 `UndergroundPolishTerrainGenerationVersion = 28`，新世界使用 v28。
  显式 v1–v27 保持原生成输出；旧世界不升级、回填或重置。save12／map4／settings11 不变。
- 精修大洞室的非对称岩肩与低台、裂隙顶高、两类目的地拱顶、矿室木支架与行走带、
  苔石室连续湿润铺地和低台、浅水池岸材。使用既有方块，不增加资源、容器或奖励。
- `UndergroundPolish` 是只依赖计划 key 与局部整数坐标的纯值规则；生产接入仍是
  `CaveGenerator::projectAdventureUndergroundImpl`，只在 v28+ 分支调用。
  地表、生态、水系、洞口及地下候选计划、地点、植被与更新顺序沿用原路径。

## 安全与用途

- 所有投影限制在 v23 已认证列及原 Y 范围内，不增加世界／邻区块读取、采样器、缓存、规划
  搜索半径或冲突规则。仍遵守最低 Y8、覆盖层至少5格、入口避让、目标区块裁剪与确定顺序。
- 入口到洞室、洞室到目的地的三格宽／三格高干燥路线保留；原台阶与跳步返回语义保持。
  岩肩和低台避开中心轴，最终干燥路线维护仍执行。
- 矿室三道门架保留原横截面位置，横梁分级抬高并补面连接；纵梁连接门架。
  检查实际木块可通过六邻面抵达有支撑的立柱，不能只靠角点相接。
- 苔石室的淤泥核心、苔石与砾石外缘形成连续斑块，低台位于矿脉对侧。
  九块目的地矿石保持原位置、身份和外露；矿室箱子与所有火把、箱内物品完全保持。
- 水体方块及池底保持，岸线只在原池岸位置切换两种实心材料。
  岩肩／顶高变化不改变物理照明传播语义；可见阴影变化来自几何变化。
- 资源移除、容器删除及保存重开继续使用现有权威路径，新外观不能令资源重生。
