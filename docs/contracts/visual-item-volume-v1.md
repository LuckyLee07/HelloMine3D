# 视觉升级：手持与掉落物体积 v1

综合视觉 Goal 第 4 阶段。表现只消费物品、材料分面和已发生动作；不得改变判定、开采速度、
耐久、库存、掉落、吸取半径、碰撞或存档格式。

- 方块采用注册的顶部、侧面、底面六面几何。非立方物品按有效资源包的 16×16 图标 Alpha
  生成前后面与轮廓侧壁，厚度 0.15 单位；透明内部边不生成。最坏棋盘遮罩为 514 个面。
- 手持与世界掉落复用同一有界 CPU 几何缓存。手持通过透视投影、背面剔除、深度排序和
  分面着色绘制，掉落走真实 Ogre 三维几何与已存在地形材质路径，支持资源包与标准/兼容档。
- ItemEntity 仅在 copied ActorSnapshot 中追加材质、数量和年龄；age/位置/物品仍由既有模拟
  与保存字段持有。旋转与轻微悬浮只属于 renderer，生命周期与拾取结果不变。
- 方块掉落保留整周旋转；挤出图标朝向观察者，局部偏转限制在 -4° 至 36°，维持至少 80%
  正面投影，避免剑、锭等薄物品侧转后消失。Reduced 缩小摆幅，Off 关闭随时间的摆动与悬浮；
  随观察位置改变的朝向只属于可读性表现，不写回 Actor 的旋转或存档。
- 手持待机、移动、连续开采、接触和恢复的位移角度有界，复用现有反馈与短暂停顿；
  Reduced 缩小幅度，Off 固定姿态。物品只占屏幕右下角，不覆盖准星和中央快捷栏。
- 第一人称玩家使用空手、握图标物品、托方块三种缓存姿态，每种最多 54 个着色四边形。
  袖口、手掌、拇指与指节有独立体积；手臂和物品共用刚性姿态、透视、背面剔除和深度排序，
  不另起动作时钟。空槽仍显示手臂；制作、容器、暂停时隐藏，窄窗口按快捷栏右侧余量缩小。
  表面明暗随已复制的 daylight 在 42%–100% 曝光之间变化，不额外查询世界光照。
  这只建立第一人称身体存在感，不声明已有第三人称全身模型或动物体系。

检查：纯几何分面、透明遮罩、侧壁数量、顶点/UV/法线边界、快照身份与独立性；已有动作、
掉落、库存、存档完整 WorldRuntime 双配置；客户端 Debug/Release；真实窗口多帧观察三种
反馈档位、连续采集/攻击/拾取与保存重开；性能纳入最终同条件三轮比较。

第一人称手部局部批次另用 `bash scripts/verify_player_hand_presentation.sh Debug` / `Release`
检查几何预算、法线/退化面、透视安全余量、刚性抓握、Off、Reduced、动作停止与非有限输入；
配合受影响客户端双配置、P11A/P11B/ITEM_VISUAL 定向回归和同机位昼夜/窄窗口/面板/连续帧。
既有矿石采集诊断夹具可检查动态渲染，但不代替正常输入玩法验收。
