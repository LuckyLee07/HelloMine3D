# r34 游戏界面：行囊、储物与合成

起点 `fe6e457`。本批工程、限定布局、诊断 CUA 交互、相关性能及干净候选交付已通过。
本批完成不等同整套 UI 达到用户要求；常驻 HUD、机器、菜单仍按
[游戏 UI 方向](../current/game-ui-direction-2026-09-20.md)继续。

用户指出当前 UI 缺少游戏产品质感；实查同时发现 640×480 点／1.25 字号时，原箱子窗口的
快捷栏数量和关闭操作落到可见区域外。本批因此从修复截断扩展为统一的“野外行囊”设计。

## 实现

- 共用物品槽：深墨蓝凹面、细包边、沙金选择角标、悬停与按压反馈；快捷栏共用该语言。
- 箱子：专用物品徽记标题、九格图标、数量角标、真实图集与既有几何组成的体积预览；固定五格行囊和关闭入口。窄窗口减少预览装饰并调整格数排列。
- 合成：材料列表与网格分区、固定产物预览和主次操作；全部制作显示真实批次数，成功反馈占用固定结果行，操作前后不会推挤网格。长说明换行，材料区独立滚动。
- 共用 `GameInterfaceWidgets.h` 只绘制，不持有物品或执行转移。继续使用既有 InventoryProvider、CraftingSession、预览和原子提交；没有引入拖拽、稀有度或虚构容量，存档不变。

## 失败、修正与真实缺项

- `baseline-r1` 保留旧箱子底部截断；`candidate-r1/r2` 保留仅修布局阶段，未作为最终设计交付。
- `design-r3` 保留真实 ImGui 布局边界错误；r4 又发现外层滚动条、窄窗口预览挤压和字幕遮挡，后续修正；r5 的清空按钮裁切也已修复。
- `engineering-r5/input-Release.log` 保留新增八个双语 key 后仍期待 470 项的失败；改为严格 478 项、保留双语完全同键要求，并增加六项本批文本断言，r6 双配置通过。
- `interaction-cua-r6` 暴露产物状态第三行裁切；r8 暴露空配方手册说明不换行；r9 暴露成功反馈推挤网格。原图均保留，最终 r10 CUA 复查通过。
- 初次直接启动的诊断进程未被 CUA 正确发现；误选的菜单已退出、未进入旧世界，`open --env` 的 -10810 失败保留。之后使用同一工作包的临时隔离启动器完成操作，并恢复原启动器和设置；这是实现者诊断交互，不冒充正式干净包正常玩法或独立验收。
- 石剑不可存箱是现有工具保护规则，本批不改变；限制反馈仍待产品交互完善。材料子区的滚动条轨道点击有效，r9 的滚轮／拖动未验证成功，不将其记为正常物理输入通过，也不重启已暂缓的持续输入调查。
- 关闭面板后看到英文 640×480／1.25 旧 HUD 生命、提示、字幕拥挤及区域名截断，明确列为下一批。完整机器布局、暂停／设置和主菜单仍待升级；独立动物、第三人称全身玩家和综合目标未完成。
