# r35 常驻 HUD：任务、状态与导航

起点 `0c2d826`。用户授权细化任务区、生命与快捷栏、小地图和提示排布，随后明确要求使用
图像生成素材，并强调与方块沙盒题材协调。本批实现、限定视觉／交互、相关性能和干净候选已交付；整套 UI 与综合目标仍未完成。

## 设计与实现

| Before | After | Why |
| --- | --- | --- |
| 任务各行接近等重，缺少可识别的视觉主题 | 像素叶片标识、当前目标主标题、次级旅程总数、分离的说明与进度 | 先识别当前目标，再读行动与完成量。 |
| 生命、物品名、状态和快捷栏各自堆叠 | 固定底座、心形生命图标与数字、十段生命条、五格槽位、固定冷却行 | 保留扫读顺序，状态出现或消失不推挤快捷栏。 |
| 英文区域名受地图圆盘宽度限制；右侧提示与地图拥挤 | 标签单独测量宽度、轻薄石灰色外圈、外置四向方牌、居中地名与双侧刻度 | 真实地图内容优先，长区域名完整，减少附属面板。 |
| 操作、字幕、状态消息争夺中心视野 | 关联当前持物的键帽提示条；紧凑窗口左右通知区；宽窗口在底座上方排布 | 保留准星和观察空间。 |
| 低生命整屏红框持续闪烁 | 稳定的短四角提醒、心形／数字／生命段同步变化 | 危险可辨，避免持续闪动；Full／Reduced／Off 规则保留。 |
| 暂停／设置字幕可能压住底部操作 | 为底部字幕预留 64 点空间；小窗口通过已有滚动访问操作 | 字幕不覆盖保存与退出入口。 |

使用内置 OpenAI `imagegen` 生成 `SandboxPanel.png` 与 `SandboxGlyphs.png`，共约 1.5 MiB PNG。
前者为低对比度深绿／灰石底板，后者为像素叶片与可着色心形。九宫格只拉伸边和中心，
图形使用 nearest 后恢复线性采样。文字、数量、冷却、物品图标、地图样本和导航标记继续来自真实运行数据。
初始化加载两份纹理，关闭时释放；未添加世界查询、存档字段、玩法状态或输入等待动画。
资源清单、生成脚本及 macOS 资产检查包含新文件；生成脚本也补齐既有代码加载的菜单背景声明。

素材／完整提示词／哈希见 [素材来源](../art-sources/field-kit-ui-r35/README.md)。
生成器给底板画出的外部棋盘格不是 Alpha；重试仍如此。最终使用原始 RGB PNG 中经检查无棋盘格的
矩形区域 `.064..936`，不采样外部背景。图形图集具有真实 Alpha。原图未作离线像素编辑。

## 已发现并修正的问题

- `engineering-r1` 因隔离根未复制 victory fixture 失败；补齐原始 fixture 后重跑，未修改或放宽测试。
- `candidate-r1` 英文紧凑窗口的中央字幕覆盖准星；r2 将紧凑窗口字幕／消息分到左右区域。
- `interaction-r2` 暂停页字幕压住退出区域；r3 预留底部空间，实际设置／取消／保存退出复查通过。
- 第一轮代码面板偏保守；写实木纹／黄铜素材随后被用户指出过于细腻，橙色像素木框／铁角件也被否定为突兀。
  两套草稿均保留在本地 `rejected-art-r4/r5`，未作为交付风格。
- 用户认可基于实际场景的轻量整屏设计方向后，改为深绿／灰石底、像素叶片与心形、简洁地图刻度。
  该设计图是生成的草图；`quiet-r9`、`matrix-r10`、`compass-r11` 与 `final-r12` 才是实际运行窗口原图。

用户随后指出地图与获认可草图不一致：r10 只有北向圆标、单边比例尺。r11/r12 补回外置四向方牌、
清晰内侧刻度和居中地名／刻度，双语实际字形与空间均复查。比例尺端点间距对应 32 个采样间隔，
按地图步长显示 32／64／128 m，保留真实距离，不固定照抄生成草图中的数字。
本批覆盖初始任务说明的换行，不声称逐一测试了全部 33 个任务；实机 CUA 与最终被动地图修正保留各自版本身份。
