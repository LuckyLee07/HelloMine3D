## 玩家可见的结果

| 地区 | 地貌和生态组合 |
| --- | --- |
| 草甸与河谷 | 低缓丘陵、开阔草地、河湾，保留观察远处地标的空地 |
| 温带林地 | 起伏与林间盆地，橡树和浅色阔叶树混合，林床、蕨类及疏密斑块 |
| 针叶高地 | 抬升丘脊、坡肩与山口，分层锥形树冠、低地被与裸岩 |
| 干燥沙丘 | 有方向且弯曲的沙脊、谷间通路，稀疏仙人掌与沙石过渡 |
| 岩台峡谷 | 高台、阶坡及切谷，岩石、黏土、坡积材料与稀疏植物 |
| 浅水湿地 | 浅池、泥岸和干地，低垂树冠、芦苇与水岸空隙 |
| 雪线山地 | 连续高脊、鞍部和雪坡，低处针叶林与裸岩，波动雪线 |
| 海岸与岛屿 | 陆海场形成海湾和孤立陆块，沙岸、砾岸、棕榈或低矮草地；不同岛屿植被规模不同 |

大尺度陆海及区域骨架、中尺度脊谷／沙丘／岸线、小尺度地表与植被斑块共同进入真实生成。区域过渡同时混合地形与生态；水系按有界局部下坡关系组织，实际水柱、表面查询、结构和植物共用生成结果。保留局部终止水塘，不声明完整流域模拟或水流物理。

新增雪、砾石、黏土、林床、苔石和淤泥接入实际方块、物品、采集及保存。树型不再仅为橡树缩放：针叶、浅色阔叶、低垂湿地树和沿海棕榈配合已有仙人掌，地被由区域、坡度和岸线共同决定。修正林床／黏土重复对比、雪图块边缘污染及岩石规则色带，保留体素像素尺度。

八个固定 seed 从生产出生点检查安全支撑、附近木材、水岸、相邻区域及三类地标接近路线；seed 42 的三条陆路分别约 320、400、320 米，水岸路线 356 米。调查逐格检查坡差，真实画面另作连续观察；查询路线不冒充正常碰撞步行。洞口通道有植被避让，营地可进入林间平地，旧主线地点身份保持。
