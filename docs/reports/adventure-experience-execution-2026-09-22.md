## B0 新增系统预算

以下为本 Goal 新能力的上限，进入对应实现前在合同明确统计与边界测试，不替代旧系统已有上限。

| 系统 | 上限／约束 |
| --- | --- |
| B1 天空 | 复用现有天空绘制，不新增 draw call；不新增纹理、RTT、世界查询或逐帧 CPU 噪声；shader 循环须固定有界 |
| 新动物 | 每世界最多 24 个活跃自然动物，玩家 64 m 内最多 12 个；不占用或暗改敌人难度名额 |
| 动物决策 | 每只最多 5 Hz 决策，新增地面／避障查询全局每 fixed tick 最多 48 次，轮转避免饥饿；禁止无界路径搜索 |
| 动物／玩家几何 | 每动物最多 8 个盒体部件（96 三角形），玩家最多 12 部件；动物总新增顶点不超过 10,000，不增加逐实例纹理 |
| 地图 | 继承局部 65×65、195 列／更新和 30 Hz 预算；持久地图运行缓存 ≤16 MiB，磁盘每世界 ≤64 MiB，个人标记 ≤64；满额有提示／明确降采样策略 |
| 声音 | 保留现有全局 16 声部、32 样本、4 MiB 解码样本预算；环境层最多 3 个同时发声，不能饿死交互／危险提示 |
| 相机／地区氛围 | 只查询驻留／纯派生值，不同步加载未知区块；插值与遮挡检测次数在各批合同固定 |

帧时间与内存实际基线保存在三档性能原始记录；上述预算在效果和性能实测前冻结，不因超限结果自动上调。
